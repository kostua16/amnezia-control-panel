## Your Task

Run a multi-model review panel, merge findings into one plan, implement through delegates.

### Steps

1. Load the T3 tools with ToolSearch, call `orchestrator_capabilities` once per thread, and confirm every named provider/model is available. If one is not, say so; do not substitute silently.
2. Review: one `delegate_task` per reviewer, same brief for all (target, scope, "read-only review, report findings with file:line and severity"). Do not poll; follow each delegate's `next`.
3. If a reviewer fails (e.g. gemini "Verification Required"), retry the same model; if it fails repeatedly, report it and continue with the rest.
4. Consolidate: dedupe findings, drop ones contradicted by verified source, separate real risks from theoretical ones. Ask the user before reversing any decision they already confirmed.
5. Plan: ask the named planner model (or yourself) for ONE consolidated update plan; then delegate implementation to the named implementer agents, with file ownership split so they do not overlap.
6. Verify the result yourself (lint, Prettier, tests per repo rules) before reporting.

### Guardrails

- Every new review/re-check is a new `delegate_task`, not a follow-up message to an old one.
- Include work context, reports path and plans path in each delegate brief (repo orchestration protocol).
- Fix small review findings yourself; do not spawn a delegate for them.
- Cancel (`task_cancel`) delegates you replace; never leave duplicates running.
