## Summary
PR #775 fixes four stuck-PR failure modes: (1) merge token permission denial in pr-finalizer.yml (contents:read→write + PAT merge), (2) finalizer apply failures retrying instead of parking on manual-only, (3) gh() maxBuffer overflow silencing check status, and (4) PR Policy transient label API errors parking green PRs. Three quick tasks: standardize maxBuffer across 5 sibling scripts, add apply-layer test for the PAT merge path, and fix a duplicate PM63 ID in the e2e docs. Three phase suggestions: shared gh() wrapper module, centralized merge-credential policy, and retry/resilience wrapper for all gh() calls.
