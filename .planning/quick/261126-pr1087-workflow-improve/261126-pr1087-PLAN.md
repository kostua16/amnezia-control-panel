## Quick Wins
- Bound fetchCompletedRuns with a server-side 'created=>=' filter -- In the new .github/workflows/scripts/aggregate-run-costs.cjs, fetchCompletedRuns calls 'gh api repos/{repo}/actions/workflows/{workflowFile}/runs --paginate -f status=completed' and filters the 168h window only client-side. The hourly monitor accumulates runs forever, so every hourly cost-telemetry job re-downloads the whole run history (8+ pages today, growing unbounded), wasting REST quota (counted by the log-rate-limit gh wrapper wired via setup-environment) and 10-min job budget. Add '-f created=>=${since}' as a server-side qualifier (list-workflow-runs supports 'created'), keep the client-side sinceMs filter as belt-and-braces, and extend __tests__/aggregate-run-costs.test.cjs to assert the created qualifier is passed. (owner: kos-fix-issue, type: quick-task)
- Remove the dead 'errors' array in fetchCompletedRuns -- aggregate-run-costs.cjs declares 'const errors = []' in fetchCompletedRuns, returns it, and never pushes to it: a mid-pagination gh failure is all-or-nothing through execFileSync (runGh returns ok:false for the whole call), so partial-pages-plus-errors cannot occur. Remove the dead field (or implement real per-page error surfacing if that was intended) and update the affected tests. The 'errors.length > 0' check in collectCostTelemetry then only reacts to the invalid-since / runs-list failure paths, which is the actual contract documented in MON-E06c (docs/workflow-e2e-scenarios.md). (owner: kos-fix-issue, type: quick-task)
- Mark MON-E06 DONE in docs/TODOs-2.md and link PR #1087 -- The PR ships MON-E06 but does not touch docs/TODOs-2.md. Per the file's own DONE-marker convention (WHO-E02 at docs/TODOs-2.md:70), update the MON-E06 row (docs/TODOs-2.md:255) to note what landed in PR #1087 (job-log-sourced aggregation into the retained monitor-cost-telemetry-<run_id> artifact, MON-E06a-d scenarios) and what stays open — the row's original 'aggregate into the metrics store' goal is only partially met; store ingestion remains under XC-5 (docs/TODOs-2.md:281). Docs-only change; no workflow gates needed beyond lint/prettier. (owner: kos-docs-drift, type: quick-task)
