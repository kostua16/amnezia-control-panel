## Summary
PR #1137 auto-fixes npm audit findings from run 44955406659: next 16.3.6→16.4.6 (GHSA-rhh4-g77r-r9qj), brace-expansion 5.0.8→5.0.13, minimatch@3-scoped brace-expansion 1.1.22 (review-corrected from unscoped key that also forced 1.x into minimatch@11), new exact 'effect: 3.22.5' override (@prisma/config pins effect@3.20.0 exact so audit fix cannot move it), plus lockfile refresh (prisma 7.10.1, typescript-eslint 8.73.0, sharp 0.35.5). ## Quick Wins
- Add override pin-resolution gate to supply-chain.yml -- supply-chain.yml runs only 'npm audit signatures' + 'npm audit --audit-level=high' (lines 43-47); nothing verifies the pins actually resolve. npm silently downgrades inert override keys to a warning, so a future prisma (effect declared exactly 3.20.0) or typescript-eslint/minimatch bump could drop brace-expansion@5.0.13 or effect@3.22.5 out of the tree and reopen GHSA-7589-6fvf-x4pw / the 2026 brace-expansion advisories with a green CI. Add a small .github/workflows/scripts/ check that asserts 'npm ls effect brace-expansion' versions equal the package.json 'overrides' values, and wire it into the supply-chain job after npm ci. (owner: ci-maintainer, type: quick-task)
- Add .github/CODEOWNERS for dependency files -- No .github/CODEOWNERS exists in this repo, and the only thing that caught the unscoped 'minimatch' override key silently forcing brace-expansion 1.x into the minimatch@11 chain (corrected to 'minimatch@3' in this PR's review) was ad-hoc reviewer attention. Map package.json, package-lock.json, and docs/npm-overrides.md to the maintainer team so required reviewers are assigned automatically on dependency PRs from the _auto-fix-ci.yml / approve-auto-fix.yml chain. (owner: repo-maintainer, type: quick-task)

(owner: repo-maintainer)
