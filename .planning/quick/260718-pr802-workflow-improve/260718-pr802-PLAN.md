## Summary
PR #802 reroutes parked dead letters to retry before priority escalation (fixing #759 shadowing), adds daily nudge dedupe, inert-attempt cooldown waiver, manual-park guard, and makes manual-only visibility preserve achieved review signals. Two sharp follow-up themes: the collect-step routing is outgrowing its inline YAML home, and the manualTerminal N/A guard pattern is now copy-pasted across 4 workers.

- DRY up manualTerminal N/A guard into a shared helper -- orchestrate-pr-flow.cjs:646,697,748,798 — the 'if (manualTerminal && !hasAny(labels, [...]))' pattern is copy-pasted 4 times with different label sets. Extract 'hasReviewSignal(labels, signalLabels)' to avoid divergent future patches. Same pattern will be needed for any new review worker added to the flow. (owner: claude, type: quick-task)
- Harden extractCollectScript() test extraction against YAML reformatting -- issue-catch-up-collect.test.cjs:141-163 uses 'bodyIndent = 12' hardcoded. Add a boundary assertion that checks the extracted script starts with a known anchor line (e.g. the twoDaysAgo/sevenDaysAgo declaration) and ends before the next 'name:' step. (owner: claude, type: quick-task)
- Document Kilo verdict asymmetry in manualTerminal guard -- orchestrate-pr-flow.cjs:798 changed kiloReview guard from 'manualTerminal' to 'manualTerminal && externalReview.state === 'pending''. Unlike the other 4 workers this checks externalReview state not labels. If Kilo posts verdict labels in the future, the guard would need updating — document this asymmetry in a code comment. (owner: claude, type: quick-task)
