# Quick Plan: PR #1052 workflow improvement intake

## Source
- PR #1052: fix: resolve #1050 - APR-I07: Pass '--title-prefix' to duplicate detection (audit-auto-prs)
- URL: https://github.com/kostua16/amnezia-control-panel/pull/1052

## Summary
PR #1052 wires --title-prefix into audit-auto-prs.yml's find-duplicate-automation-pr.cjs call, scoping duplicate detection to only automation PRs sharing that title prefix. The fix is correct and narrowly scoped. Two follow-ups surfaced: (1) gsd-planning-execute.yml has two identical calls to the same script that lack --title-prefix despite generating predictable title prefixes; (2) the overlap-matrix subcommand in audit-auto-prs also lacks --title-prefix (line 241), which means the matrix could include non-automation PRs in its output if the label filter is misconfigured.

## Quick Wins
- Add --title-prefix to gsd-planning-execute.yml duplicate detection calls -- Lines 316 and 535 of gsd-planning-execute.yml call find-duplicate-automation-pr.cjs without --title-prefix. The workflow generates PRs with predictable prefixes ('planning: promote deferred proposal' and 'chore(planning): track execution queue plan'). Without scoping, duplicate detection scans all 100 open PRs — slower and susceptible to cross-family false positives on shared .planning/ files. (owner: workflow-maintainer, type: quick-task)
- Pass --title-prefix to the overlap-matrix call in audit-auto-prs.yml -- Line 241 of audit-auto-prs.yml runs find-duplicate-automation-pr.cjs --overlap-matrix --overlap-label auto-fix but omits --title-prefix. The matrix's runOverlapMatrix() function reads --title-prefix (find-duplicate-automation-pr.cjs:504) to scope candidate PRs. Without it, the matrix includes ALL PRs with the auto-fix label regardless of family, producing noise in the step summary. Passing the same prefix used in the duplicate check (line 131) keeps the matrix consistent. (owner: workflow-maintainer, type: quick-task)

## pr1052.x Phase Candidates
- pr1052.2: Centralize automation PR title-prefix registry to prevent missing-prefix regressions -- Five workflows (audit-auto-prs, fix-issue, maintenance, suggest-improvements, monitor-amnezia-control-panel-github-runs) each hardcode a --title-prefix string when calling find-duplicate-automation-pr.cjs. Two more (gsd-planning-execute, workflow-health-optimize) omit it. A shared registry (e.g. .github/workflows/scripts/automation-prefixes.json or a shared action output) that find-duplicate-automation-pr.cjs could consume would eliminate the class of bug #1050 represents: adding a new workflow and forgetting to scope its duplicate detection. (owner: workflow-maintainer)
