## Quick Wins
- Make install-governance-yaml.sh mktemp portable and add an executed installer test -- Gate: only once #1182 is merged (see Precondition); edit the merged .github/workflows/scripts/install-governance-yaml.sh. The script creates the parser path with `mktemp "$RUNNER_TEMP/governance-yaml-XXXXXX.cjs"`; the X run is not last and no --suffix is passed. Verified on this runner (Ubuntu image, BusyBox v1.37.0 and uutils coreutils 0.10.0): busybox mktemp rejects that template ('Invalid argument', exit 1) and also rejects --suffix ('unrecognized option', exit 1), while uutils accepts both; GNU coreutils on ubuntu-latest could not be verified from here. Required fix, one form only: put the X run last on a directory and give the parser an explicit .cjs name -- `parser_dir="$(mktemp -d "$RUNNER_TEMP/governance-yaml-XXXXXX")"; parser="$parser_dir/js-yaml.cjs"` (verified on this runner: busybox and uutils both accept it). Do not use the extensionless `mktemp "$RUNNER_TEMP/governance-yaml-XXXXXX"` form: require() routes a no-extension file through the .js loader, so its module type comes from Node's format detection rather than from the file name (verified on Node 24.22.3: it loaded as CommonJS even under a 'type': 'module' scope, but that is detection, not a guarantee). Do not use `--suffix=.cjs` either: it fails on busybox. The two new tests in workflow-yaml-parse.test.cjs only regex the script text, so a runtime fault in the script, the tarball member path package/dist/js-yaml.cjs.js, or the checksum step surfaces only when supply-chain.yml and workflow-governance.yml run. Make the archive source overridable so an executed test never downloads, and make the override test-only and fail closed: the installer takes a local archive path and its expected digest from env (GOVERNANCE_YAML_ARCHIVE_PATH and GOVERNANCE_YAML_ARCHIVE_SHA512) only behind an explicit fixture opt-in -- GOVERNANCE_YAML_ALLOW_FIXTURE=1 must be set alongside the path for the fixture branch to activate and skip curl, and a digest override without that opt-in must be refused with a non-zero exit, so nothing that controls the job environment can pair an arbitrary archive with a matching digest and silently bypass the SHA-512 trust anchor the installer exists to enforce. The registry URL and the expected digest stay the script's literal defaults because the lockfile-drift test greps for that literal digest. Only the unit test may set these variables: supply-chain.yml and workflow-governance.yml must never set any of the three, and the real download plus checksum verification stays in those jobs, which already call the installer. Add to workflow-yaml-parse.test.cjs: (a) a text assertion for the required `mktemp -d` call and the .cjs parser name, so a revert to either rejected form fails the suite; (b) one test that assembles a fixture tarball at test time from the lockfile-installed node_modules/js-yaml/dist/js-yaml.cjs.js laid out as package/dist/js-yaml.cjs.js, computes its sha512 digest in the same base64 form the script uses, executes the script with RUNNER_TEMP and GITHUB_ENV pointed at temp files and GOVERNANCE_YAML_ALLOW_FIXTURE=1 plus both override variables set, then runs GOVERNANCE_YAML_PARSER=<path> node .github/workflows/scripts/workflow-governance-check.cjs; (c) a negative case that passes the fixture path (with the fixture opt-in) but not the digest override, so the script compares the fixture against the pinned default digest and fails the integrity comparison. Assert that failure specifically, not as a bare non-zero exit: with 'set -euo pipefail' an unset GOVERNANCE_YAML_ARCHIVE_SHA512, a missing package/dist/js-yaml.cjs.js member in the tar extraction, or the post-extraction bundle check all exit non-zero too, so a status-only assertion can pass without ever reaching the integrity comparison. Capture the script output and require the exact mismatch line the merged script prints ('::error::Governance YAML parser integrity check failed') plus evidence the download branch was skipped (the fixture archive was the source, no registry.npmjs.org access); (d) one case proving the fail-closed gate: with GOVERNANCE_YAML_ARCHIVE_SHA512 set but GOVERNANCE_YAML_ALLOW_FIXTURE unset, the script refuses the override and exits non-zero asserting its refusal message, so the override can never silently re-anchor trust. No test may reach registry.npmjs.org. (owner: claude, type: quick-task)
