## Summary
PR #883 fixes git auth failure in pr-improve.yml by removing redundant git fetch after persist-credentials:false checkout. Fix is correct — fetch-depth:0 already provides all refs. No other workflows share the exact same latent pattern.

Add fallback fetch so the fetch is a retry, not a primary call — hardens against edge cases without reintroducing the auth failure. (owner: workflow-maintainer, type: workflow-improvement)
