## Summary
PR #1019 adds the APR-E10 escalate-repeated-fixes script and thorough unit tests, but the script is never invoked by audit-auto-prs.yml. Additional concerns: fragile merged-PR detection, TOCTOU race on escalation creation, and missing e2e coverage.

## Quick Wins
- Wire escalate-repeated-fixes.cjs into audit-auto-prs.yml -- The script exists at .github/workflows/scripts/escalate-repeated-fixes.cjs but no step in audit-auto-prs.yml calls it. The structured_output is already a job output (line 47). Add a new step or small job between audit-auto-prs and publish-digest that runs the script with --repo, --structured-output, and --run-url. Without this wiring, APR-E10 is dead code. (owner: workflow-infrastructure, type: quick-task)
- Harden hasMergedFixPr search to match by label or issue reference -- In escalate-repeated-fixes.cjs:571, hasMergedFixPr searches for the internal fingerprint hash in merged PR text. Developers fixing the issue won't know to include the hash, so the check always returns false and escalations fire perpetually. Add a secondary check: search for the escalation issue number via 'Fixes #N' patterns in merged PR bodies. (owner: workflow-infrastructure, type: quick-task)
- Add APR-E10 entries to workflow-e2e-scenarios.md -- Per CLAUDE.md workflow change protocol, workflow additions require e2e scenario entries. The APR-E10 flow (log upsert, streak counting, escalation creation) has no rows in docs/workflow-e2e-scenarios.md. Add rows for first-run log creation, second-run escalation trigger, merged-PR suppression, and concurrent-run guard. (owner: workflow-infrastructure, type: quick-task)

## pr1019.x Phase Candidates
- pr1019.1: Add idempotency guard for concurrent escalation issue creation -- In escalate-repeated-fixes.cjs:534, findEscalationIssue and createEscalationIssue have a TOCTOU race: two concurrent audit runs can both read null and create duplicate escalation issues. The log issue mitigated this by passing existingNum (line 486), but escalation issues lack this guard. Implement a compare-and-swap: re-search before creating, or use deterministic titles with post-create dedup cleanup. (owner: workflow-infrastructure)
- pr1019.2: Add APR-E10 characterization test to e2e suite -- The e2e suite (.github/workflows/scripts/__tests__/*.test.cjs) validates workflow script integration. The new script has unit tests but no e2e scenario test validating full main() flow with gh CLI context. A characterization test prevents regressions in the CI pipeline integration path. (owner: workflow-infrastructure)
- pr1019.3: Verify APR-E10 escalation issues route through triage workflow -- Escalation issues get labels auto-fix, needs-review, umbrella-sub-issue (line 322) but there is no explicit verification that this combination is trusted by policy.json or the triage workflow trigger config. If untrusted, escalation issues sit untriaged, defeating their purpose. (owner: workflow-infrastructure)
