# Summary: PR #237 workflow improvement intake

- Source PR: https://github.com/kostua16/amnezia-control-panel/pull/237
- Summary: PR #237 fixes a circular-dependency stall in the PR finalizer: `gh pr checks --required` was picking up `pr-flow/ready` as a required check, creating a deadlock where the finalizer couldn't succeed because the finalizer itself was responsible for setting that status. The fix replaces `--required` with a config-driven filter (`filter-required-pr-checks.cjs`) that reads only the CI jobs listed in `pr-flow.json`, and adds auto-merge retry logic so the orchestrator re-dispatches the finalizer when a prior run succeeded without enabling auto-merge. Well-tested with 4 new test cases covering the core scenarios.
