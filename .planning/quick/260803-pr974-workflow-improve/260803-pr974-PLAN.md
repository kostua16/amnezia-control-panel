# Quick Plan: PR #974 workflow improvement intake

## Source
- PR #974: fix: resolve #973 - Security: weekly npm audit found HIGH+ advisories
- URL: https://github.com/kostua16/amnezia-control-panel/pull/974

## Summary
PR #974 manually patched HIGH+ npm audit advisories in 'balanced-match' (transitive via 'brace-expansion@5') by adding overrides in 'package.json'. CI already runs 'npm audit --audit-level=high' on every PR and weekly. Dependabot is configured for weekly npm updates. The gap: 'balanced-match@4.0.4' had a known vuln but Dependabot can't auto-create override PRs — it only bumps direct deps. The manual override pattern works but is reactive.

## Quick Wins
- Add comment documenting why each override entry exists -- package.json overrides block (lines 61-67) has 6 entries with zero comments explaining why each override exists. Adding '// CVE-YYYY-XXXX: desc' or '// audit: reason' per entry lets future maintainers know which are security-driven vs compatibility-driven and when they can be removed. (owner: claude, type: quick-task)
- Pin brace-expansion overrides to exact patched versions -- The new overrides use caret ranges (^5.0.8, ^1.1.17) which allow future minor bumps that may re-introduce the vulnerable transitive. Pin to exact patched versions (5.0.8, 1.1.18) in overrides since these are security pins, not feature deps. (owner: claude, type: quick-task)

## pr974.x Phase Candidates
- pr974.2: Auto-fix workflow for npm audit HIGH+ advisories -- The weekly 'security-audit-weekly.yml' only opens an issue when advisories are found — it never attempts 'npm audit fix'. Add a step that runs 'npm audit fix' (or targeted overrides) on a branch and opens a PR when the fix is clean, falling back to the existing issue-only path when automatic resolution fails. This closes the gap where Dependabot handles direct deps but transitive vulns like balanced-match require manual overrides. (owner: claude)
- pr974.3: Require manual review for PRs adding new override entries -- Overrides bypass the normal dependency resolution tree. The 'dependency-review.yml' agent reviews Dependabot PRs but has no policy for override additions. Add a check in 'pr-policy.yml' (or 'evaluate-pr-policy.cjs') that flags PRs touching the 'overrides' block in package.json with a 'needs-review' label, since each override is a trust decision about transitive dep versions. (owner: claude)
