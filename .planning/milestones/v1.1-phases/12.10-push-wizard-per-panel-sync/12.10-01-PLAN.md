<objective>
Fix the `generatePerPanelConfig` Xray rule filter to scope routing rules to the matched node only (same pattern as wireguardPeers), and update the corresponding test.

Per D-01 (CONTEXT.md): Fix Xray rule panel scoping so each panel receives only its own rules.

Purpose: Currently `generatePerPanelConfig` filters Xray rules by checking if `rule.nodeId` matches ANY chain node label (via `nodeLabels.has()`). This means every panel gets ALL chain routing rules regardless of ownership. The fix aligns the filter with the wireguardPeers pattern which already correctly scopes by `matchedNode.label`.

Output: Fixed filter logic in `panel-sync-client.ts`; updated test expectation in `panel-sync-client.test.ts`.
</objective>
