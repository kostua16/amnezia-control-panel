**Exports:**

1. `ResolvedTransport` interface:
```typescript
export interface ResolvedTransport {
  /** Canonical URL for reaching the remote panel: https://<tailscaleIP>:<port> */
  panelUrl: string;
  /** The Tailscale IPv4 address used */
  tailscaleIP: string;
  /** The hostname that resolved to the IP */
  hostname: string;
  /** The port used for the panel URL */
  port: number;
  /** Whether the node is online per tailscale status */
  online: boolean;
  /** Which resolution tier succeeded */
  source: 'db' | 'cli-resolve' | 'fallback' | 'panel-url-direct';
}
```

2. `resolvePanelTransport` async function:
```typescript
export async function resolvePanelTransport(
  server: { id: number; tailnetIP?: string | null; tailnetHostname?: string | null; hostname: string },
  panel: { panelUrl: string },
  defaultPort = 443,
): Promise<ResolvedTransport | null>
```

**Implementation logic (extracted from tailnet/route.ts lines 42-92):**

- **Tier 1 (DB):** If `server.tailnetIP` is truthy, use it directly. Set `hostnameUsed = server.tailnetHostname ?? server.hostname`, `source = 'db'`.
- **Tier 2 (CLI tailnetHostname):** If Tier 1 failed and `server.tailnetHostname` is truthy, call `getNodeIP(server.tailnetHostname)`. If IP returned, set `hostnameUsed = server.tailnetHostname`, `source = 'cli-resolve'`.
- **Tier 3 (CLI hostname fallback):** If both tiers above failed, call `getNodeIP(server.hostname)`. If IP returned, set `hostnameUsed = server.hostname`, `source = 'fallback'`.
- **All tiers failed:** Return `null`.
- **Cache-back (DB write):** If `source !== 'db'`, call `prisma.server.update` to set `tailnetIP = resolvedIP` and `tailnetHostname = hostnameUsed`. Import prisma via `await import('./prisma')` to match the lazy pattern used in panel-sync-client.ts line 176.
- **Online check:** Call `isReachable(hostnameUsed)` (from tailscale.ts) for the `online` field.
- **panelUrl construction:** Use `new URL()` with `https://` protocol, `tailscaleIP`, and `defaultPort`. Result: `https://${resolvedIP}:${defaultPort}`. Do NOT use string concatenation.
- **Non-throwing pattern:** Return `null` on failure, never throw. Wrap the entire function body in try/catch returning null on unexpected errors. Log errors with `console.error('[transport-resolver] ...')`.

**Imports:**
```typescript
import { getNodeIP, isReachable } from './tailscale';
```
Do NOT import `prisma` at the top level -- use dynamic import inside the function body to avoid circular dependencies and match the project pattern.

**DO NOT:**
- Import NextResponse or any Next.js server-side types (this is a plain utility, not a route handler)
- Add WebSocket broadcast events (this is a pure resolution utility)
- Hand-roll DNS resolution -- use `getNodeIP` from tailscale.ts which calls `tailscale ip -4` via CLI
