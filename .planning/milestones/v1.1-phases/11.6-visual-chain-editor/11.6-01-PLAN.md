  <action>
    **Step 1: Install dependency**
    Run: `npm install @xyflow/react`

    **Step 2: Create src/lib/chain-flow-utils.ts**
    This file provides conversion between the app's domain types and React Flow's Node/Edge types.

    Export the following functions:

    1. `interface ChainBuilderNode` -- copy from chain-builder.tsx lines 19-25:
       ```typescript
       export interface ChainBuilderNode {
         id: string;
         serverId: number | null;
         label: string;
         role: ChainNode['role'];
         protocol: ChainNode['protocol'];
       }
       ```

    2. `toFlowNodes(builderNodes: ChainBuilderNode[], positions: Record&lt;string, {x: number; y: number}&gt;): Node&lt;{data: ChainBuilderNode}&gt;[]`
       - Converts ChainBuilderNode[] to React Flow Node[] using the Node type from @xyflow/react
       - Each node: `{ id, type: 'chainNode', position: positions[id] ?? {x: CANVAS_PADDING, y: CANVAS_PADDING}, data: { ...builderNode } }`
       - Use `CANVAS_PADDING` from chain-layout.ts as fallback position

    3. `toFlowEdges(connections: Array&lt;{fromId: string; toId: string}&gt;, isCrossPanel?: (sourceId: string, targetId: string) =&gt; boolean): Edge[]`
       - Converts connection pairs to React Flow Edge[]
       - Each edge: `{ id: 'edge-{fromId}-{toId}', source: fromId, target: toId, type: 'smoothstep', animated: false }`
       - If isCrossPanel is provided and returns true for the pair, set: `style: { stroke: '#94a3b8', strokeWidth: 2.5, strokeDasharray: '8 4' }`, `data: { crossPanel: true }`
       - Default (intra-panel) edge style: `{ stroke: '#94a3b8', strokeWidth: 1.5 }`
       - Arrow marker: React Flow built-in arrow

    4. `getDefaultPositions(nodeCount: number, topology: ChainTopology): Record&lt;string, {x: number; y: number}&gt;`
       - Wraps `calculateNodePositions` from chain-layout.ts
       - Generates IDs `node-0`, `node-1`, etc.
       - Returns a Record mapping node ID to position

    5. `reassignRoles(nodes: ChainBuilderNode[]): ChainBuilderNode[]`
       - If nodes.length === 0 return []
       - First node: role = 'entry'
       - Last node (if >1): role = 'exit'
       - Middle nodes: role = 'middle'
       - Return new array (do not mutate)

    6. `generateNodeId(): string` -- returns `'node-' + Date.now()`
  </action>
