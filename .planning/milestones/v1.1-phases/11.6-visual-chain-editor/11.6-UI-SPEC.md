## React Flow Canvas Configuration

### Canvas
- Background: transparent (inherits `--background` from page)
- Grid: dotted grid using React Flow `Background` variant, color `#334155` (`--border`) at 20px spacing, 1px line width
- Fit view: auto-fit on initial load and after topology change, with `padding: 0.2` (20% padding), animated transition `duration: 300ms`
- Min zoom: 0.3, Max zoom: 2

### Controls
- Built-in React Flow `Controls` component, positioned bottom-right
- Built-in React Flow `MiniMap` component, positioned bottom-left
- MiniMap styling: node color based on role badge color, panel group nodes rendered as semi-transparent rectangles in minimap

### Edges
- Default (intra-panel): smooth step or bezier, `stroke: #94a3b8` (muted-foreground), `strokeWidth: 1.5`, solid
- Cross-panel: `stroke: #94a3b8`, `strokeWidth: 2.5`, `strokeDasharray: "8 4"`, with animated dash on hover
- Edge arrows: React Flow built-in arrow marker, filled with edge stroke color
- Selected edge: `stroke: #3b82f6` (accent), `strokeWidth: 2.5`
- Edge label (optional): none by default; cross-panel edges show tooltip on hover with "Source Panel -> Target Panel"

### Nodes (chain nodes as custom React Flow nodes)
- Custom node type: `ChainFlowNode` -- wraps existing `ChainNodeCard` design patterns
- Width: 200px (`w-50`), height: auto (min ~100px)
- Background: `bg-card`, border: `border border-border`, shadow: `shadow-md`
- Selected state: `border-accent ring-2 ring-accent/30`
- Handles: 4 handles (top, bottom, left, right) -- React Flow `Handle` components
  - Handle style: `w-2.5 h-2.5 rounded-full bg-accent border-2 border-background`
  - Handle hover: `bg-accent/80 scale-110` (subtle grow)
  - Left/right handles used for linear connections, top/bottom for split/mesh
- Drag: native React Flow DnD (no custom drag implementation)
- Click: opens routing rules drawer for that node's panel

### Group Nodes (panel boundaries)
- Custom node type: `PanelGroupNode` -- wraps React Flow `Group` node type
- Styling: `bg-card/20 border-2 border-dashed border-muted-foreground/40 rounded-lg`
- Label: positioned top-left inside the group, `text-xs font-medium text-muted-foreground bg-background/80 px-2 py-0.5 rounded`
- Sizing: auto-calculated from child nodes with 16px padding on all sides (`style: { padding: 16 }`)
- Cannot be directly dragged to resize -- sizing is automatic

## Panel Boundary Visualization (CONTEXT.md D-19, D-20)

### Grouping Logic
- Each `RemotePanel` maps to one or more `Server` instances
- Each `ChainNode` references a `serverId`, which maps to a panel via the server->panel relationship
- Nodes with the same panel ownership are wrapped in a single `PanelGroupNode`
- Nodes with no server assigned (unassigned) are placed outside any panel group

### Visual Distinction
- Panel group: lighter, dashed background -- clearly distinguishable from chain node cards
- Panel group contains: chain nodes + their inter-node connections
- Between groups: cross-panel connections styled as thicker dashed lines (see Color section)
- Unassigned nodes: sit on the canvas outside any group, with a visual cue (subtle pulsing border or "unassigned" badge)

## Inline Routing Rule Editing (CONTEXT.md D-21, D-22)

### Trigger
- Click on any chain node in the React Flow canvas opens a right-side drawer

### Drawer Configuration
- Width: `w-[480px] max-w-full` (wider than the 384px used in geo-rule-drawer to accommodate a rules table + form)
- Position: `fixed inset-y-0 right-0 z-50`
- Backdrop: `fixed inset-0 z-50 bg-black/50` (same as existing drawer pattern)
- Close: backdrop click, Escape key, X button in header

### Drawer Contents
- **Header**: Node label + role badge + "Routing Rules" subtitle
- **Tabs** (matching existing `RoutingRulesTabs` pattern):
  - "Geo" -- geo rules filtered to this chain
  - "IP & Domain" -- IP/host rules filtered to this chain
  - "Templates" -- template gallery (same as routing rules page)
- **Rule list**: compact table showing rules applicable to this chain/node
- **Add rule**: opens inline form or reuses existing `GeoRuleDrawer` pattern within the drawer (slide-over within slide-over, or accordion expand)
- **Footer**: "Apply to Panels" primary CTA button (pushes updated rules to remote panels)

### Auto-save
- Changes to rule fields auto-save with 500ms debounce
- Debounced API call to existing `/api/routing/geo` (and related routes)
- Visual indicator: small "Saving..." spinner (Loader2 icon from lucide-react) in the rule row being edited, replaced by a brief green checkmark on success
- "Apply to Panels" button is separate from auto-save -- it triggers config push to remote panels (existing `/api/chains/apply` endpoint)

## Interaction Patterns

### Node placement
- "Add Node" opens dropdown of available servers; selecting one creates a new `ChainFlowNode` at the center of the current viewport
- Newly placed node auto-selects and shows a subtle highlight animation
- Node can be dragged to reposition within the canvas (native React Flow DnD)

### Connection creation
- Drag from a source handle (the accent-colored circle on a node edge) to a target handle on another node
- Valid connections: any node to any other node (no self-loops)
- Connection preview shown while dragging (React Flow built-in)
- Duplicate connections are rejected silently (React Flow validates automatically)

### Node selection
- Click a node to select it (blue ring highlight)
- Click canvas background to deselect
- Selected node opens the routing rules drawer

### Node removal
- Remove button inside the node card (same pattern as existing `ChainNodeCard`)
- Confirmation dialog: "Remove this node and all its connections?"
- On confirm: node and all connected edges are removed; roles reassigned (entry/exit/middle)

### Connection removal
- Click an edge to select it, then press Delete key or click a "Remove" button that appears in a small floating toolbar near the edge
- Confirmation dialog: "Remove this connection?"
- On confirm: edge is removed

### Panel boundary display
- Panel boundaries are always visible (not toggleable)
- When a node's server assignment changes, it moves into the appropriate panel group (or out of all groups if unassigned)
- Auto-layout: when topology changes, nodes reposition within their panel groups; panel group sizing adjusts automatically

### Routing rules editing (within drawer)
- Tab switching between Geo / IP & Domain / Templates (same pattern as `RoutingRulesTabs`)
- Geo rules: filtered to the chain this topology belongs to (matches CONTEXT.md: "editor filters rules by the chain this topology belongs to")
- Inline edit: click a rule row to expand an edit form (accordion style) within the drawer
- Create: "Add Rule" button at bottom of rules list opens inline create form
- Auto-save with 500ms debounce; visual spinner during save
- "Apply to Panels" button in drawer footer triggers push (uses existing `/api/chains/apply`)

## Accessibility Notes

- React Flow canvas: standard React Flow accessibility (nodes are focusable, arrow keys for navigation within the flow)
- Keyboard: Delete key removes selected edge/node (after confirmation); Escape closes drawer/deselects
- Focus management: when routing drawer opens, focus moves to the first interactive element in the drawer; on close, focus returns to the clicked node
- ARIA: panel group nodes have `role="group"` with `aria-label="{Panel Name}"`; chain nodes have `aria-label="{Node Label}, {Role}"`
- Handles (connection ports): `aria-label="Connect from {node label}"` / `aria-label="Connect to {node label}"`
- Icon-only buttons (remove connection, zoom controls): must include `aria-label`
- Focus visible: `focus-visible:ring-2 focus-visible:ring-ring` (global, already in `globals.css`)
- Drawer: backdrop click closes; Escape closes (matches existing drawer pattern)
- Color contrast: node text on `bg-card` (#1e293b) background with #f8fafc text passes WCAG AA (contrast ratio ~13:1); muted-foreground (#94a3b8) on card background passes AA for large text
