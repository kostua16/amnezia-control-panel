```prisma
// ─── RemotePanel ─────────────────────────────────────

model RemotePanel {
  id          Int      @id @default(autoincrement())
  name        String
  panelUrl    String
  apiKeyHash  String
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  connectionHistory PanelConnectionHistory[]

  @@map("remote_panels")
}

model PanelConnectionHistory {
  id        Int      @id @default(autoincrement())
  success   Boolean
  latencyMs Int?
  message   String
  version   String?
  checkedAt DateTime @default(now())

  panel     RemotePanel @relation(fields: [panelId], references: [id], onDelete: Cascade)
  panelId   Int

  @@index([panelId])
  @@index([checkedAt])
  @@map("panel_connection_history")
}
```

**Key decisions applied:**
- Separate `RemotePanel` model (not reusing Server model) per CONTEXT.md decision
- `apiKeyHash` stored as bcrypt hash (matches Server model pattern)
- `PanelConnectionHistory` as separate model (last 10 per panel, with cascade delete)
- `version` field stores remote panel version string from connectivity test responses
- Indexes on `panelId` and `checkedAt` for query performance on history lookups

  ```typescript
    panelUrl: panel.panelUrl,

    updatedAt: panel.updatedAt.toISOString(),

  ```
- Return `{ success: true, data }` with 200
- Error: return `{ success: false, error: 'Failed to fetch remote panels' }` with 500

**POST handler:**
- Zod schema:
  ```typescript
  const createPanelSchema = z.object({
    name: z.string().min(1, 'Panel name is required').max(100, 'Panel name must be at most 100 characters'),
    panelUrl: z.string().min(1, 'Panel URL is required').max(500, 'Panel URL must be at most 500 characters').url('Invalid URL format'),
    apiKey: z.string().min(1, 'API key is required'),
  });
  ```
- Parse body with `createPanelSchema.safeParse(body)`, return 422 with first error on failure
- Hash API key: `const bcrypt = await import('bcryptjs'); const apiKeyHash = await bcrypt.hash(apiKey, 10);`
- Create panel: `prisma.remotePanel.create({ data: { name, panelUrl, apiKeyHash } })`
- Return `{ success: true, data: { id, name, panelUrl, isActive, createdAt, updatedAt } }` with 201
- Handle P2002 unique constraint (return 409 with 'Panel URL already exists')
- Error: return 500 with 'Failed to create remote panel'

- 404 if not found
- Return `panelResponse(server)`

**PUT handler:**
- Zod schema:
  ```typescript
  const updatePanelSchema = z.object({
    name: z.string().min(1).max(100).optional(),
    panelUrl: z.string().min(1).max(500).url().optional(),
    apiKey: z.string().min(1).optional(),
    isActive: z.boolean().optional(),
  });
  ```

- Parse body, return 422 on validation failure
- Find existing panel (404 if not found)
- Build `updateData` object conditionally for each provided field
- If `apiKey` is provided, hash it: `updateData.apiKeyHash = await bcrypt.hash(apiKey, 10);`
- Update: `prisma.remotePanel.update({ where: { id: panelId }, data: updateData })`

- Handle P2002 unique constraint (409)
- Error: 500

**DELETE handler:**
- Parse `id`, validate as number
- Find existing panel (404 if not found)
- Delete: `prisma.remotePanel.delete({ where: { id: panelId } })` -- cascade deletes connection history automatically
- Return `{ success: true, data: { id: panelId } }`
- Error: 500

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> /api/panels | Untrusted browser input (panel name, URL, API key) |
| API key in transit | API key travels over HTTPS from browser to central panel API |
| API key in storage | API key hashed with bcrypt before SQLite storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11.2-01 | S (Spoofing) | POST /api/panels | mitigate | API key hashed with bcrypt (cost=10) before storage; plaintext never persisted. Auth middleware (existing) protects all routes. |
| T-11.2-02 | T (Tampering) | PUT /api/panels/:id | mitigate | Zod validation on all input fields. URL field validated with `.url()`. No raw SQL (Prisma parameterized queries). |
| T-11.2-03 | I (Info Disclosure) | GET /api/panels | mitigate | Response mapper explicitly strips `apiKeyHash` from all API responses. Only returns id, name, panelUrl, isActive, timestamps. |
| T-11.2-04 | D (Denial of Service) | POST /api/panels | accept | No rate limiting needed at 1-admin scale. Input length bounds via Zod `.max()` prevent oversized payloads. |
| T-11.2-05 | E (Elevation of Privilege) | DELETE /api/panels/:id | mitigate | Existing auth middleware on all /api/ routes. Only authenticated admin can delete. |
</threat_model>
