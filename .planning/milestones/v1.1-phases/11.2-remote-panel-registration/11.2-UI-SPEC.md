## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline padding (`px-1`), status dot margin |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`), badge padding (`py-0.5 px-2`) |
| md | 16px | Default form spacing (`space-y-4`), table row padding (`py-3 pr-4`) |
| lg | 24px | Section padding (`p-6` on CardHeader/CardContent), section gaps (`space-y-6`) |
| xl | 32px | Layout gaps between major blocks (`space-y-8`) |
| 2xl | 48px | Empty state vertical padding (`py-12`) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Icon buttons: 40px (`h-10 w-10`) — matches existing `size="icon"` button pattern
- Sidebar nav item padding: 32px horizontal (`px-3`) + 8px vertical (`py-2`) via `gap-3` + icon 16px
- Main content area padding: 16px mobile, 24px desktop (`p-4 sm:p-6`) — established in dashboard-layout.tsx

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 (default) |
| Label | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Heading | 18px (`text-lg`) | 700 (bold, via `font-bold`) | 1.2 (via `leading-none`) |
| Display | 24px (`text-2xl`) | 700 (bold, via `font-bold`) | 1.2 |

Notes:
- Page title uses `text-2xl font-bold` (matches existing server-list.tsx heading pattern)
- Subtitle uses `text-sm text-muted-foreground` (matches existing description pattern)
- Card titles use `text-lg font-bold` (mapped from `font-semibold` to `font-bold`)
- Card descriptions use `text-sm text-muted-foreground` (matches existing CardDescription)
- Form labels use `text-sm font-medium text-foreground` — `font-medium` (500) accepted here as it is the existing component pattern from `@/components/ui/label`; new custom markup must use `font-normal` (400) or `font-bold` (700) only
- Table headers use `text-sm font-medium` — same existing component exception as form labels

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (--background) | Page background, main content area |
| Secondary (30%) | `#1e293b` (--card) | Cards, sidebar (`--muted: #334155`), table rows |
| Accent (10%) | `#3b82f6` (--accent) | Primary CTA buttons, sidebar active indicator, focus rings |
| Destructive | `#ef4444` (--destructive) | Delete button icon color, error states, destructive actions |

Accent reserved for:
1. "Add Panel" primary CTA button (`Button` default variant)
2. Sidebar active nav item indicator (left border + background tint)
3. Focus-visible ring outline (`--ring: #3b82f6`)

Status badge colors (CONTEXT.md decision: badge-based green/yellow/red):
- Connected: `bg-green-500` dot + `bg-green-500/10 border-green-500/20` card tint
- Degraded: `bg-yellow-500` dot + `bg-yellow-500/10 border-yellow-500/20` card tint
- Offline: `bg-red-500` dot + `bg-red-500/10 border-red-500/20` card tint
- Unknown: `bg-gray-400` dot + `bg-muted border-border` card tint

Latency badge thresholds (default, Claude's discretion):
- Green: latency <= 100ms
- Yellow: latency 101-500ms
- Red: latency > 500ms or connection failed

## Interaction States

| State | Visual Treatment |
|-------|-----------------|
| Loading (initial) | Centered spinner (`RefreshCw animate-spin`) + "Loading panels..." text (matches server-list.tsx) |
| Loading (test) | Spinning `RefreshCw` replaces `TestTube` icon, button disabled |
| Loading (submit) | Button text changes to "Adding..." / "Saving...", button disabled |
| Empty | Centered card with `Monitor` icon (h-12 w-12), heading, body, CTA button (matches server-list.tsx empty state) |
| Success (test) | Green banner: `bg-green-50 text-green-800 dark:bg-green-900/20 dark:text-green-400` (matches add-server-form.tsx) |
| Error (test) | Red banner: `bg-red-50 text-red-800 dark:bg-red-900/20 dark:text-red-400` (matches add-server-form.tsx) |
| Row actions | `opacity-0 group-hover:opacity-100 transition-opacity` (matches server-list.tsx action column pattern) |
| Destructive pending | Button disabled while delete in progress (matches server-list.tsx `deletingId` pattern) |
