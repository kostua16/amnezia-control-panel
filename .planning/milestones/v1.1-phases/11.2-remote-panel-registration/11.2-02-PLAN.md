**`testPanel(panelId: number): Promise<PanelTestResult>`**
- Fetch panel from DB: `prisma.remotePanel.findUnique({ where: { id: panelId } })`
- Return `{ success: false, latencyMs: null, message: 'Panel not found', version: null, timestamp: new Date().toISOString() }` if not found
- Measure latency with `const startTime = Date.now();`
- Make HTTP GET request to `{panel.panelUrl}/api/health` using `fetch()` with headers: `{ 'Authorization': 'Bearer {apiKeyHash}' }`
  - IMPORTANT: The remote panel health endpoint expects the API key in the Authorization header. Since we store the hash (not the plaintext key), we cannot authenticate to the remote panel directly. For now, use a simple TCP-level reachability check instead:
  - Use `fetch(panel.panelUrl, { method: 'HEAD', signal: AbortSignal.timeout(5000) })` to test reachability
  - If fetch succeeds (any 2xx-5xx response): panel is reachable, record latency
  - If fetch fails (network error, timeout): panel is unreachable
- Calculate latency: `const latencyMs = Date.now() - startTime;`
- Build result object:
  ```typescript
  {
    success: reachable,
    latencyMs: reachable ? latencyMs : null,
    message: reachable ? `Panel reachable (${latencyMs}ms)` : `Cannot reach ${panel.panelUrl}`,
    version: null,  // Will be populated when remote panel implements version endpoint
    timestamp: new Date().toISOString(),
  }
  ```
- Save result to DB: `prisma.panelConnectionHistory.create({ data: { panelId, success: result.success, latencyMs: result.latencyMs, message: result.message, version: result.version } })`
- Prune old records (keep last 10):
  ```typescript
  const historyCount = await prisma.panelConnectionHistory.count({ where: { panelId } });
  if (historyCount > 10) {
    const excess = historyCount - 10;
    const oldRecords = await prisma.panelConnectionHistory.findMany({
      where: { panelId },
      orderBy: { checkedAt: 'asc' },
      take: excess,
      select: { id: true },
    });
    if (oldRecords.length > 0) {
      await prisma.panelConnectionHistory.deleteMany({
        where: { id: { in: oldRecords.map(r => r.id) } },
      });
    }
  }
  ```
- Return the PanelTestResult

**`export type PanelConnectionStatus = 'connected' | 'degraded' | 'offline' | 'unknown';`**

**`getPanelStatus(panelId: number): Promise<{ status: PanelConnectionStatus; lastRecord: PanelConnectionRecord | null }>`**
- Fetch most recent history record: `prisma.panelConnectionHistory.findFirst({ where: { panelId }, orderBy: { checkedAt: 'desc' } })`
- If no records: return `{ status: 'unknown', lastRecord: null }`
- Derive status from most recent record:
  - `success === true && latencyMs !== null && latencyMs <= 100`: `'connected'`
  - `success === true && latencyMs !== null && latencyMs <= 500`: `'degraded'`
  - `success === true && latencyMs !== null && latencyMs > 500`: `'degraded'`
  - `success === false`: `'offline'`
  - Otherwise: `'unknown'`
- Map record to PanelConnectionRecord shape (convert DateTime to ISO string)
- Return `{ status, lastRecord }`

**`startPanelHealthChecks(): void`**

**`stopPanelHealthChecks(): void`**

```typescript
import { NextRequest, NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';
import { testPanel } from '@/lib/panel-health-checker';

type RouteContext = { params: Promise<{ id: string }> };

export async function POST(_request: NextRequest, context: RouteContext) {
  try {
    const { id } = await context.params;
    const panelId = Number(id);
    if (Number.isNaN(panelId)) {
      return NextResponse.json(
        { success: false, error: 'Invalid panel ID' },
        { status: 422 },
      );
    }

    const panel = await prisma.remotePanel.findUnique({ where: { id: panelId } });
    if (!panel) {
      return NextResponse.json(
        { success: false, error: 'Panel not found' },
        { status: 404 },
      );
    }

    const result = await testPanel(panelId);

    return NextResponse.json({ success: true, data: result });
  } catch (err) {
    console.error('[api/panels/:id/test] Error:', err);
    return NextResponse.json(
      { success: false, error: 'Connection test failed' },
      { status: 500 },
    );
  }
}
```

**Create `src/app/api/panels/[id]/status/route.ts`** with GET handler:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';
import { getPanelStatus } from '@/lib/panel-health-checker';

type RouteContext = { params: Promise<{ id: string }> };

export async function GET(_request: NextRequest, context: RouteContext) {
  try {
    const { id } = await context.params;
    const panelId = Number(id);
    if (Number.isNaN(panelId)) {
      return NextResponse.json(
        { success: false, error: 'Invalid panel ID' },
        { status: 422 },
      );
    }

    const panel = await prisma.remotePanel.findUnique({ where: { id: panelId } });
    if (!panel) {
      return NextResponse.json(
        { success: false, error: 'Panel not found' },
        { status: 404 },
      );
    }

    const { status, lastRecord } = await getPanelStatus(panelId);

    // Also fetch last 10 history records for display
    const history = await prisma.panelConnectionHistory.findMany({
      where: { panelId },
      orderBy: { checkedAt: 'desc' },
      take: 10,
    });

    return NextResponse.json({
      success: true,
      data: {
        panelId,
        status,
        lastRecord,
        history: history.map((h) => ({
          id: h.id,
          success: h.success,
          latencyMs: h.latencyMs,
          message: h.message,
          version: h.version,
          checkedAt: h.checkedAt.toISOString(),
        })),
      },
    });
  } catch (err) {
    console.error('[api/panels/:id/status] Error:', err);
    return NextResponse.json(
      { success: false, error: 'Failed to fetch panel status' },
      { status: 500 },
    );
  }
}
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11.2-06 | S (Spoofing) | fetch(panel.panelUrl) | accept | HEAD-only request, no sensitive data sent. At 1-admin scale with Tailscale mesh, network is already trusted. |
| T-11.2-07 | T (Tampering) | PanelConnectionHistory | mitigate | Only internal code writes to history (no user input directly). Prisma parameterized queries. |
| T-11.2-08 | I (Info Disclosure) | GET /api/panels/:id/status | mitigate | History contains only connectivity metadata (latency, success/fail, version). No API keys or credentials exposed. |
| T-11.2-09 | D (Denial of Service) | startPanelHealthChecks | mitigate | 30s interval is reasonable. Each test has 5s timeout via AbortSignal. Try/catch per panel prevents cascade failures. |
| T-11.2-10 | R (Repudiation) | PanelConnectionHistory | accept | Audit logging not needed at 1-admin scale. History is for debugging, not compliance. |
