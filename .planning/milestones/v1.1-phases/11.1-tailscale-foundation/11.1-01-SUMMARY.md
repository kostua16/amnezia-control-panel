## Decisions Made
- **advertisedSubnets as JSON String**: SQLite Prisma connector does not support `String[]` (lists of primitive types). Stored as `String @default("[]")` with JSON encoding. TypeScript interface retains `string[]` type; conversion happens at application layer.
- **resolveTransportAddress bonus export**: Added getNodeIP-based transport address resolver as a convenience function for downstream consumers.
- **PublicKey stripped in toNodeInfo**: Per T-11.1-02 threat mitigation, sensitive crypto material is excluded from normalized node info.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] SQLite does not support String[] in Prisma**
- **Found during:** Task 2 (Extend Prisma Server model)
- **Issue:** Plan specified `advertisedSubnets String[] @default([])` but SQLite Prisma connector raised P1012: "Field can't be a list. The current connector does not support lists of primitive types."
- **Fix:** Changed to `advertisedSubnets String @default("[]")` -- JSON-encoded string. TypeScript interface retains `string[]` type; conversion happens at application layer.
- **Files modified:** prisma/schema.prisma
- **Verification:** `prisma db push` succeeded, `prisma validate` passed, `prisma generate` succeeded.
- **Committed in:** `d406be8` (Task 2 commit)
