# Phase 11.7 -- UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual Tailwind CSS v4 + hand-rolled UI primitives) |
| Preset | not applicable |
| Component library | none (custom `src/components/ui/`: Button, Card, Input, Dialog) |
| Icon library | lucide-react |
| Font | Arial, Helvetica, sans-serif (system); Geist Sans / Geist Mono available via Next.js |

**Existing primitives in `src/components/ui/`:**
- `Button` -- variants: default, destructive, outline, ghost; sizes: default (h-10), sm (h-8), lg (h-12), icon
- `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter` -- rounded-lg border-border bg-card
- `Input` -- standard text input
- `Dialog` -- modal with backdrop, Escape-to-close, focus trap

**Established compound patterns to reuse:**
- Template card grid: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4` (see `template-gallery.tsx`)
- Template card button: `rounded-lg border p-4` with selected state `ring-2 ring-accent border-accent bg-accent/5` (see `chain-templates-list.tsx`)
- Slide-over drawer: `fixed inset-y-0 right-0 z-50 w-96 max-w-full border-l border-border bg-background shadow-lg` (see `template-apply-drawer.tsx`)
- Segmented tab control: `flex items-center gap-1 rounded-md border border-border p-1` with variant toggle buttons (see `config-list.tsx`)
- "Built-in" badge: `text-xs bg-blue-500/10 text-blue-400 px-2 py-0.5 rounded-full` (see `template-gallery.tsx`)
- Error banner: `rounded-md border border-destructive/50 bg-destructive/10 px-3 py-2 text-sm text-destructive`
- Empty state: centered column with 64x64 muted icon circle + heading + body text (see `template-gallery.tsx`)
- Service badge: AWG = blue tint, 3x-ui = green tint, Any = muted (see `config-list.tsx`)
- Loading spinner: `Loader2 className="h-6 w-6 animate-spin text-muted-foreground"` centered
- Protocol icon: per-protocol colored lucide icons (Shield=blue for WG, Zap=green for VLESS, Globe=orange for VMess, etc.)

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge padding (`px-2 py-0.5`) |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`), table cell padding |
| md | 16px | Default element spacing (`p-4`, `gap-4`, `space-y-4`), card internal padding |
| lg | 24px | Section padding (`p-6`), CardHeader/CardContent padding |
| xl | 32px | Layout gaps, major section separators |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Tab segmented control uses 4px padding (`p-1`) around toggle buttons
- Icon-only badge containers: 32x32px (`h-8 w-8`) for consistency with existing chain template icons
- Drawer width: 384px (`w-96`) fixed, matching existing `TemplateApplyDrawer`

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 (default) |
| Label | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Heading | 18px (`text-lg`) | 600 (semibold) | 1.2 (tight) |
| Display | 20px (`text-xl`) | 600 (semibold) | 1.2 (tight) |

**Context:** The existing codebase uses `text-sm` as the default body size, `text-xs` for metadata/badges/muted text, and `text-lg font-semibold` for card titles and section headings. The sidebar uses `text-sm font-medium` for nav items. Only 2 font weights are declared: 400 (regular) for body and label text, and 600 (semibold) for heading and display text.

**Supporting semantic colors (pre-existing in `globals.css`):**
- `--muted: #334155` -- inactive backgrounds, badges, borders
- `--muted-foreground: #94a3b8` -- secondary text, descriptions
- `--border: #334155` -- card borders, table dividers
- `--brand-success: #22c55e` -- success indicators
- `--brand-warning: #eab308` -- warning indicators

Accent reserved for:
- Active/selected template card ring and tint
- "Use This" / "Apply" primary action buttons
- Tab active indicator in segmented control
- Active sidebar nav border-left indicator

## Component Inventory

This phase introduces the following components. All must follow existing patterns documented above.

### 1. Template Gallery Page (`/templates`)

**File:** `src/app/(dashboard)/templates/page.tsx`

Full-page layout inside the existing `(dashboard)` route group with sidebar.

**Structure:**
```
Page Header (h1: "Templates" -- text-xl font-semibold)
Tab Bar (segmented control: Protocols | Server | Routing | Chain)
Content Area (switches based on active tab)
```

**Tab bar:** Reuse segmented control pattern from `config-list.tsx`. Four tabs:
- `Protocols` -- VPN protocol templates (TMPL-01)
- `Server` -- Server/VPS presets (TMPL-02)
- `Routing` -- Geo rule bundles (TMPL-03)
- `Chain` -- Chain presets (TMPL-04)

**Default tab:** Protocols

### 2. Protocol Templates Tab

**Content:** Card grid of VPN protocol templates. Each card shows:
- Protocol icon (colored, per existing `ProtocolIcon` pattern)
- Template name (text-sm font-medium)
- "Built-in" badge if applicable
- Service badge (AWG / 3x-ui / Any)
- Description (text-xs text-muted-foreground, 2-line clamp)
- Two actions: "Preview" (outline button, opens preview modal), "Use This" (primary button)

**Layout:** `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`

**Built-in protocols (4+):** VLESS-REALITY, Hysteria2, TUIC, plus existing protocol templates from DB.
**Custom templates:** Listed alongside built-ins, without "Built-in" badge, with delete action visible.

**"Save as Template" entry point:** Primary CTA button above the grid (top-right), labeled "Save Current as Template". Opens a Dialog with name + description fields.

### 3. Server Presets Tab

**Content:** Card grid of server presets. Each card shows:
- Provider/OS icon (lucide: `Server`, `Cloud`, `HardDrive`)
- Preset name (e.g., "Hetzner Ubuntu 24.04")
- Provider badge (text-xs rounded-full bg-muted)
- Configuration summary: OS, recommended MTU, kernel modules
- "Use This" primary button

**Layout:** `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`

**Built-in server presets (4+):** Hetzner, DigitalOcean, Vultr, Contabo (all with Ubuntu 24.04 defaults). Server presets are in-memory (extend existing `ConfigPreset` array), not in DB.

**No custom server presets in this phase** -- server presets remain built-in only.

### 4. Routing Presets Tab

**Content:** Card grid of routing rule bundles. Each card shows:
- Bundle icon (lucide: `Globe` for geo-related)
- Bundle name (e.g., "Russia Direct", "EU Privacy", "Full Tunnel")
- "Built-in" badge
- Description (text-sm text-muted-foreground)
- Rule count badge (text-xs in muted pill)
- "Preview" (outline) and "Apply" (primary) buttons

**Layout:** `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`

**Apply behavior:** Append mode -- preset rules are added below existing custom rules. Admin reorders after. Show a toast/notification confirming: "Added N rules from [preset name]. Review and reorder on the Routing Rules page."

**Built-in routing bundles (3):** "Russia Direct", "EU Privacy", "Full Tunnel"

### 5. Chain Presets Tab

**Content:** Card grid of chain presets. Each card shows:
- Chain icon (lucide: per existing iconMap)
- Preset name (e.g., "Simple Relay", "Privacy Chain", "High Performance")
- Topology badge (colored pill: blue=linear, amber=split, green=mesh)
- Description
- Node count and server count pills
- "Preview" (outline) and "Use This" (primary) buttons

**Layout:** `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4` (matches `ChainTemplatesList` responsive behavior)

**Built-in chain presets (3):** "Simple Relay" (2-node linear), "Privacy Chain" (3-node entry+middle+exit), "High Performance" (2-node VLESS-REALITY)

### 6. Template Preview Modal

**Trigger:** "Preview" button on any template card.

**Component:** Reuse existing `Dialog` from `src/components/ui/dialog.tsx`.

**Content:**
- Header: Template name + "Built-in" badge if applicable
- Description paragraph
- Structured preview section:
  - **Protocol templates:** Show protocol name, service type, key config fields (network, security, flow) in a key-value table
  - **Server presets:** Show provider, OS, kernel parameters, recommended MTU in key-value table
  - **Routing presets:** Show rule list in table format (name, match type, action, priority) -- reuse existing `TemplateApplyDrawer` table pattern
  - **Chain presets:** Show topology diagram summary (node list with roles and protocols) + linked routing bundle name
- Footer: "Use This" (primary CTA) + "Close" (outline)

**Width:** `max-w-lg` (512px) -- wider than default `max-w-md` to accommodate table content.

### 7. "Save as Template" Dialog

**Trigger:** "Save Current as Template" button on Protocol Templates tab.

**Component:** Reuse existing `Dialog`.

**Content:**
- Text input: Template name (required, min 2 chars)
- Textarea: Description (optional, max 200 chars)
- Footer: "Save Template" (primary) + "Don't Save" (outline)
- Validation: show inline error below name input if empty or too short

### 8. Fork-to-Customize Flow

**Trigger:** Built-in template card shows a subtle "Fork" action (ghost button, text-xs with `GitBranch` icon) in the card footer alongside "Preview" and "Use This".

**Behavior:** Opens "Save as Template" dialog pre-populated with the built-in template's name + "(Copy)" suffix and its description. On save, creates a new custom template in DB with `isBuiltIn: false`.

### 9. Navigation Entry

**File:** `src/lib/navigation.ts`

Add new nav item to `NAV_ITEMS` array:
```typescript
{ label: 'Templates', href: '/templates', icon: BookTemplate }
```

**Icon:** `BookTemplate` from lucide-react (or `LayoutTemplate` as fallback).
**Position:** After "Config" (`/config`) and before "Monitoring" (`/monitoring`).

## Interaction States

### Template Card States

| State | Visual |
|-------|--------|
| Default | `border-border bg-card hover:border-accent/50 hover:bg-muted/50` |
| Hover | `border-accent/50 bg-muted/50` -- cursor pointer |
| Focus (keyboard) | `ring-2 ring-ring` (via Button focus-visible) |
| Disabled (loading) | `opacity-50 pointer-events-none` |
| Built-in read-only | No delete button shown; "Fork" action available instead |

### Tab States

| State | Visual |
|-------|--------|
| Active tab | `variant="default"` (bg-accent text-accent-foreground) |
| Inactive tab | `variant="ghost"` (transparent, text-foreground on hover) |

### Apply/Loading States

| State | Visual |
|-------|--------|
| Idle | Button text only |
| Applying (loading) | `Loader2` spinner (h-3 w-3 animate-spin) + "Applying..." text; button disabled |
| Success | Toast notification (routing apply) or navigation redirect (protocol/chain apply) |
| Error | Error banner appears above grid; existing error cleared on next action |

### Modal/Drawer States

| State | Visual |
|-------|--------|
| Open | Backdrop `bg-black/50`; content panel slides in or centers |
| Closing | Instant close (existing pattern -- no animation) |
| Escape | Closes modal/drawer |
| Backdrop click | Closes modal/drawer |
