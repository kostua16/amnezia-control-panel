# Phase 11.8 — UI Design Contract

> Visual and interaction contract for the Multi-Panel Dashboard phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Manual (hand-copied shadcn patterns) |
| Preset | Not applicable -- no `components.json` |
| Component library | Hand-copied shadcn/ui primitives (Card, Button, Dialog, Input) |
| Icon library | lucide-react |
| Font | Arial, Helvetica, sans-serif (system stack per `globals.css`) |

**Note:** This project does not use `components.json` / `npx shadcn`. UI primitives are hand-copied from shadcn/ui and live in `src/components/ui/`. Existing components must be matched exactly in style. No new shadcn init required.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline spacing |
| sm | 8px | Compact element spacing, table cell padding |
| md | 16px | Default element spacing, card content padding (`p-4`) |
| lg | 24px | Section padding (`space-y-6`), card header padding (`p-6`) |
| xl | 32px | Layout gaps between major dashboard sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level top/bottom spacing |

**Exceptions:** None. All existing components use these exact values. New components must follow.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label | 12px (`text-xs`) | 500 (medium) | 1.4 |
| Heading | 18px (`text-lg`) | 600 (semibold) | 1.2 |
| Display | 24px (`text-2xl`) | 700 (bold) | 1.2 |

**Usage mapping (from existing codebase):**
- Display: Page title `<h1 className="text-2xl font-bold">`
- Heading: Card titles `<CardTitle>` (renders as `text-lg font-semibold`), section headers
- Body: Card content, table cells, descriptions (`text-sm`)
- Label: Subtexts, timestamps, badges (`text-xs`)

Font weights used in codebase: 400 (default), 500 (`font-medium`), 600 (`font-semibold`), 700 (`font-bold`).
Contract limits to 2 primary weights: 400 (body) + 600 (headings). 500 and 700 are allowed for emphasis only.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (background) | Page background, empty areas |
| Secondary (30%) | `#1e293b` (card) | Card surfaces, dropdown panels, expanded accordion areas |
| Accent (10%) | `#3b82f6` (brand-primary) | Primary CTA buttons, active tab indicator, status "connected" dot, active filter button, focus ring |
| Destructive | `#ef4444` (brand-danger) | Offline/CRITICAL status indicators, delete actions, unread alert badge |

**Semantic severity colors (from existing `globals.css` and `alert-banner.tsx`):**

| Severity | Color | Background tint | Border tint |
|----------|-------|-----------------|-------------|
| INFO / Connected | `#3b82f6` (blue) | `bg-blue-500/10` | `border-blue-500/20` |
| WARNING / Degraded | `#eab308` (yellow) | `bg-yellow-500/10` | `border-yellow-500/20` |
| CRITICAL / Offline | `#ef4444` (red) | `bg-red-500/10` | `border-red-500/20` |

**Accent reserved for:**
- Primary CTA buttons ("Add Panel", "Retry")
- Active/selected tab in period toggle group
- Panel status dot when connected
- Focus ring (`--ring`)
- Selection highlight

Accent is NOT used for: secondary text, card borders, background fills, non-primary badges.

**Text colors (from existing CSS variables):**
- Primary text: `#f8fafc` (`text-foreground`)
- Secondary text: `#94a3b8` (`text-muted-foreground`)
- Borders/dividers: `#334155` (`border-border`)
- Muted surfaces: `#334155` (`bg-muted`)

## Layout & Interaction Contract

### Dashboard Page Structure (enhanced `src/app/(dashboard)/dashboard/page.tsx`)

```
+-------------------------------------------------------+
| Dashboard (h1, text-2xl font-bold)                    |
| Monitor your VPN services, traffic, and system...     |
+-------------------------------------------------------+
| MetricsCards (existing, unchanged)                     |
| [Total Users] [Active] [Traffic] [Services Online]    |
+-------------------------------------------------------+
| ResourceMonitor (lg:col-span-1) | TrafficStats (lg:col-span-2) |
| (existing, unchanged)           | (existing, unchanged)        |
+-------------------------------------------------------+
| --- NEW MULTI-PANEL SECTION (below existing) ---      |
+-------------------------------------------------------+
| FleetHealthStrip                                       |
| [3 Online] [1 Degraded] [0 Offline] Fleet: 1.2 GB     |
+-------------------------------------------------------+
| PanelCard Grid (1 col mobile, 2 col lg, 3 col xl)     |
| +--------------------+ +--------------------+         |
| | Panel Name         | | Panel Name         |         |
| | [Connected] 23ms   | | [Degraded] 340ms   |         |
| | 2/2 services       | | 1/2 services       |         |
| | Last sync: 30s ago | | Last sync: 2m ago  |         |
| +--------------------+ +--------------------+         |

+-------------------------------------------------------+
| (if no panels): EmptyPanelCTA                          |
| [No Remote Panels]                                     |
| Add a remote panel to see its status...                |
| [+ Add Your First Panel]                               |
+-------------------------------------------------------+
```

### Panel Card Interaction

1. **Default state:** Collapsed card showing name, `PanelStatusBadge`, latency, services count, last sync
2. **Hover:** Subtle `hover:bg-muted/50` background shift, cursor pointer
3. **Click:** Toggles Collapsible to reveal `PanelCardExpanded` with:
   - Mini `TrafficChart` (reuse existing, maxBars=12)
   - ResourceBar set for CPU/Memory/Disk (reuse `ResourceBar` pattern)
   - Smooth expand/collapse animation (CSS transition, max-height or grid-rows)
4. **Status change animation:** Panels that just changed status via WebSocket get a brief pulse (`animate-pulse` on the status dot for 2 seconds)

### FleetHealthStrip

- Horizontal bar with colored count badges
- Green badge: "N Online"
- Yellow badge: "N Degraded"
- Red badge: "N Offline"
- Right-aligned total fleet traffic
- `rounded-md border border-border bg-card p-4` matching Card style
- Uses `flex items-center justify-between`

### Responsive Breakpoints

| Breakpoint | PanelCard grid columns | TrafficChart maxBars |
|------------|----------------------|---------------------|
| < 640px (mobile) | 1 column | 8 |
| 640-1023px (tablet) | 1 column | 12 |
| 1024-1279px (lg) | 2 columns | 16 |
| >= 1280px (xl) | 3 columns | 24 |

### Loading States

- FleetHealthStrip: Skeleton bars (pulsing `bg-muted` rectangles) matching badge widths
- PanelCard grid: Skeleton cards with `animate-pulse bg-muted rounded-lg h-32`
- PanelCardExpanded: `Loader2` spinner centered, matching existing `ResourceMonitor` loading pattern

### Empty State

When `panels.length === 0`:
- Show `EmptyPanelCTA` card instead of `FleetHealthStrip` + grid
- Card with centered layout: `Monitor` icon (48px, `text-muted-foreground`), heading, body text, CTA button
- CTA navigates to `/panels` page (existing panel list with "Add Panel" button)

### Polling & Real-Time

- 30s `refetchInterval` on `useMultiPanelStatus` (matches existing dashboard polling)
- WebSocket `panel:fallback-change`: triggers immediate re-query of affected panel status
- WebSocket `panel:push-progress`: updates push state badge on PanelCard when applicable
