# Requirements: Amnezia Control Panel

**Defined:** 2026-04-27
**Core Value:** One panel, both VPN systems — users synchronized between Amnezia AWG and 3x-ui, no context switching

## v1 Requirements

### Authentication

- [x] **AUTH-01**: Admin can login with username and password
- [x] **AUTH-02**: Admin session persists across browser refreshes
- [x] **AUTH-03**: Admin can logout from any page

### User Management

- [x] **USER-01**: Admin can create user that propagates to both Amnezia AWG and 3x-ui
- [x] **USER-02**: Admin can edit user settings (name, limits, assigned protocols)
- [x] **USER-03**: Admin can delete user from both systems
- [x] **USER-04**: Admin can block and unblock user
- [x] **USER-05**: User state synchronized automatically between Amnezia AWG and 3x-ui
- [x] **USER-06**: Admin can view list of all users with their status and assigned services

### Service Management

- [x] **SERV-01**: Admin can view real-time status of Amnezia AWG service (online/offline)
- [x] **SERV-02**: Admin can view real-time status of 3x-ui service (online/offline)
- [x] **SERV-03**: Admin can install Amnezia AWG on the server from the panel
- [x] **SERV-04**: Admin can install 3x-ui on the server from the panel
- [x] **SERV-05**: Admin can uninstall Amnezia AWG from the panel
- [x] **SERV-06**: Admin can uninstall 3x-ui from the panel
- [x] **SERV-07**: Failed VPN services auto-restart with notification to admin
- [x] **SERV-08**: Admin can view current VPN configuration (ports, interfaces, DNS, protocols)

### Configuration

- [x] **CONF-01**: Auto-generation of configuration files with recommended settings for Amnezia AWG
- [x] **CONF-02**: Auto-generation of configuration files with recommended settings for 3x-ui
- [x] **CONF-03**: Protocol templates for Amnezia AWG (WireGuard, AmneziaWG with obfuscation presets)
- [x] **CONF-04**: Protocol templates for 3x-ui (VLESS, VMess, Trojan, Shadowsocks with presets)
- [x] **CONF-05**: Admin can export all configurations to file for backup
- [x] **CONF-06**: Admin can import configurations from file for restore
- [x] **CONF-07**: Recommended settings presets for common deployment scenarios

### Routing & Limits

- [x] **ROUTE-01**: Admin can set traffic quotas per user
- [x] **ROUTE-02**: Admin can set speed limits per user
- [x] **ROUTE-03**: Admin can create routing rules by user, protocol, or time schedule
- [x] **ROUTE-04**: Admin can view, edit, and reorder active routing rules

### VPN Chaining

- [x] **CHAIN-01**: Admin can add multiple VPN servers to the panel and manage them
- [x] **CHAIN-02**: Visual drag-and-drop builder for creating VPN server chain topologies
- [x] **CHAIN-03**: Auto-configuration of WireGuard/Xray routing rules for chain links
- [x] **CHAIN-04**: Geo-routing rules that route traffic based on destination geography
- [x] **CHAIN-05**: Whitelist management for local and regional services per chain node
- [x] **CHAIN-06**: Pre-built chain templates for common topologies (2-hop, 3-hop, split-routing)
- [x] **CHAIN-07**: Live visualization of chain topology with active traffic flow indicators

### Monitoring

- [x] **MON-01**: Dashboard with key metrics (users online, total traffic, service status overview)
- [x] **MON-02**: Traffic statistics per user per time period (hour, day, week, month)
- [x] **MON-03**: Server resource monitoring display (CPU, RAM, disk usage)
- [x] **MON-04**: Real-time traffic monitoring via WebSocket connection

### Alerts

- [x] **ALERT-01**: Alert notification when VPN service goes down
- [x] **ALERT-02**: Alert notification when user exceeds traffic quota
- [x] **ALERT-03**: Alert notification when server resources exceed defined threshold

## v2 Requirements

### Enhanced Monitoring

- **EMON-01**: Historical traffic analytics with charts and trends
- **EMON-02**: Connection log with per-user connection history
- **EMON-03**: Bandwidth forecasting based on usage patterns

### Advanced Chain Features

- **ACHAIN-01**: Dynamic chain re-routing based on server load
- **ACHAIN-02**: Chain health monitoring with latency metrics
- **ACHAIN-03**: Automatic chain failover when intermediate node fails

## Out of Scope

| Feature | Reason |
|---------|--------|
| Multi-admin roles / RBAC | Single administrator, no need for role management |
| End-user self-service portal | Admin-only tool, end users don't access the panel |
| Billing / payment integration | Not a commercial VPN service |
| Mobile native app | Web-first with responsive design covers mobile needs |
| Plugin system | Adds unnecessary complexity for single-admin tool |
| Multi-tenant isolation | Single server deployment, no tenant separation needed |
