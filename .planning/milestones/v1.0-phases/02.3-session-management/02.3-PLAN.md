# Phase 2.3: Session Management - Plan

**Created:** 2026-04-28
**Status:** Ready for execution

## Tasks

### Task 1: Update Login API to Set Cookie
**File:** `src/app/api/auth/login/route.ts` (MODIFY)

Add Set-Cookie header to login response. Use NextResponse cookies API:
```ts
response.cookies.set('auth-token', token, { httpOnly: true, sameSite: 'lax', path: '/', maxAge: 86400, secure: process.env.NODE_ENV === 'production' })
```

### Task 2: Create Auth Middleware
**File:** `src/middleware.ts` (NEW)

- Read auth-token cookie from request
- Verify JWT with jose
- If valid: allow request (NextResponse.next())
- If invalid/missing: redirect to /login for protected routes (/dashboard, /users, /services, /config, /monitoring, /servers, /settings)
- Skip middleware for /login, /api/*, /_next/*, static files

### Task 3: Update Auth Store Cookie Sync
**File:** `src/lib/auth-store.ts` (MODIFY)

- checkAuth() calls /api/auth/me endpoint (or reads cookie client-side)
- On login success, token already in cookie from API
