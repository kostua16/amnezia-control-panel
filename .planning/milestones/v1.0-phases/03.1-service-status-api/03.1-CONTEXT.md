# Phase 3.1: Service Status API - Context

**Gathered:** 2026-04-28
**Status:** Ready for planning

<domain>
## Phase Boundary

Create API endpoints to check AWG and 3x-ui service status. Return online/offline with timestamp. Shell commands check systemd service status.

</domain>

<decisions>
## Implementation Decisions

- **D-01:** GET /api/services/awg/status — checks amnezia-awg service via systemctl/shell
- **D-02:** GET /api/services/3x-ui/status — checks 3x-ui service via systemctl/shell
- **D-03:** Return { service: string, status: "online"|"offline", timestamp: string }
- **D-04:** Use shelljs for shell commands (already installed)
- **D-05:** Service names: "amnezia-awg" and "3x-ui" (configurable later)

### Claude's Discretion
- Exact shell commands (systemctl is-active vs service status)
- Error handling for missing services
- Response time optimization

</decisions>
