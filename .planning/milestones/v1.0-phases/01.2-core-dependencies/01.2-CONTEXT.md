<decisions>
## Implementation Decisions

### Package Selection
- **D-01:** Install all dependencies from research spec plus UI utilities
- **D-02:** Prisma ORM (latest stable) — type-safe database access with SQLite
- **D-03:** Socket.io (latest stable v4+) — WebSocket for real-time monitoring
- **D-04:** jose (not jsonwebtoken) — native Edge-compatible JWT library for Next.js API routes
- **D-05:** bcryptjs — password hashing for admin authentication
- **D-06:** ShellJS — shell command execution for VPN service management
- **D-07:** Zustand — lightweight client-side state management
- **D-08:** @tanstack/react-query — server state caching and synchronization
- **D-09:** lucide-react — icon library for admin UI
- **D-10:** recharts — charting library for traffic/resource monitoring dashboards
- **D-11:** clsx — conditional className utility
- **D-12:** zod — runtime schema validation for forms and API responses

### Claude's Discretion
- Exact version pinning strategy (latest vs caret ranges)
- Whether to add @prisma/adapter-better-sqlite3 or rely on Prisma's built-in SQLite
- TypeScript type packages for third-party libs (e.g., @types/shelljs)

</decisions>
