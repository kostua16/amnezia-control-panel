<read_first>
- CLAUDE.md (project instructions)
- .planning/phases/01.1-project-initialization/01.1-CONTEXT.md (decisions D-01, D-02, D-03)
</read_first>

<action>
Run `create-next-app` from the project root. Since the project directory already has `.git`, `.planning`, `.claude`, and `CLAUDE.md`, create the Next.js scaffold **in the current directory** using `.` as the project name.

Exact command:

```bash
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes
```

Flag breakdown:
- `.` -- initialize in current directory (project root already exists with .planning and .git)
- `--typescript` -- TypeScript configuration (D-03: Next.js defaults, strict: true)
- `--tailwind` -- Tailwind CSS setup (D-02: included now to avoid rework in Phase 1.5)
- `--eslint` -- ESLint configuration (D-02)
- `--app` -- App Router (D-02: already decided in stack)
- `--src-dir` -- organize source under src/ (D-02)
- `--import-alias "@/*"` -- standard import alias (D-03: path alias @/* -> ./src/*)
- `--use-npm` -- D-01: npm as package manager
- `--yes` -- accept all defaults without interactive prompts

If create-next-app refuses to run in a non-empty directory, initialize in a temp directory and move files:

```bash
npx create-next-app@latest amnezia-cp-temp --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes
cp -r amnezia-cp-temp/* amnezia-cp-temp/.* . 2>/dev/null || true
rm -rf amnezia-cp-temp
```

IMPORTANT: Do NOT overwrite existing files that predate this phase:
- `.git/` directory
- `.planning/` directory
- `.claude/` directory
- `CLAUDE.md`
- `vpn_features.txt`
</action>
