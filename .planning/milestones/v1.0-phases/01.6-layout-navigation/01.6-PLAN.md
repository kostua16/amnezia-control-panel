# Phase 1.6: Layout & Navigation - Plan

**Created:** 2026-04-28
**Status:** Ready for execution

## Architecture

```
src/app/(dashboard)/layout.tsx        [Server Component]
  └─ DashboardLayout                  [Client Component]
       ├─ Sidebar                     [Client Component]
       │    └─ NavItem (×7)
       ├─ MobileOverlay               [Conditional backdrop]
       ├─ Header                      [Client Component]
       │    └─ HamburgerButton        [Button ghost+icon]
       └─ <main>                      [Content area]
            └─ {children}
```

Server/Client boundary: `(dashboard)/layout.tsx` stays Server Component. Interactive parts in `DashboardLayout` client component. State: `useState(sidebarOpen)`.

## Dependency Graph

```
Task 1 (navigation.ts) → Task 2 (sidebar) + Task 3 (header)
Task 2 + 3 → Task 4 (dashboard-layout)
Task 6 (placeholder pages) → Task 5 (update layout.tsx)
```

Critical path: 1 → 2 → 4 → 5. Tasks 3 and 6 parallelizable.

## Task 2: Sidebar Component
**File:** `src/components/layout/sidebar.tsx` (NEW)

Client component. Props: `{ open, onClose, activeHref }`.
- Desktop: always visible, `lg:flex`, no transform
- Mobile: `fixed inset-y-0 left-0 w-60 z-50`, slide via `translate-x`
- Dark bg: `bg-muted`, right border: `border-border`
- Active item: `bg-accent/10 text-accent border-l-2 border-accent`
- Inactive: `text-muted-foreground hover:text-foreground`
- App title "Amnezia" at top, nav items list below

---

## Task 3: Header Component
**File:** `src/components/layout/header.tsx` (NEW)

Client component. Props: `{ onMenuClick }`.
- `h-14 border-b border-border bg-background flex items-center px-4 lg:px-6`
- Hamburger: `Button ghost+icon` with `Menu` icon, `lg:hidden`
- App title "Amnezia Control Panel"
- Right side: placeholder for future status/user avatar

## Task 4: DashboardLayout Client Component
**File:** `src/components/layout/dashboard-layout.tsx` (NEW)

Orchestrates Sidebar + Header + overlay + content.
- `useState(sidebarOpen)`, `usePathname()` for active detection
- `activeHref = '/' + pathname.split('/')[1]`
- Desktop: sidebar visible, content `lg:ml-60`, no hamburger
- Mobile: sidebar hidden, hamburger opens it with `bg-black/50` backdrop at z-40
- `<main className="flex-1 overflow-y-auto p-6">`
