# Phase 1.6: Layout & Navigation - Context

**Gathered:** 2026-04-28
**Status:** Ready for planning

<domain>
## Phase Boundary

Create the main application layout with a fixed sidebar, top header bar, and main content area. Define navigation items for all major sections. Layout must be responsive — fixed sidebar on desktop (>=1024px), overlay sidebar on mobile via hamburger toggle. Use dark theme tokens established in Phase 1.5.

</domain>

<decisions>
## Implementation Decisions

### Sidebar Layout
- **D-01:** Fixed sidebar on desktop (>=1024px), overlay on mobile with hamburger toggle
- **D-02:** Sidebar width: 240px (w-60 in Tailwind)
- **D-03:** Dark sidebar using slate-800 palette (bg-muted token), dark main area slate-900
- **D-04:** Sidebar collapsible — mobile overlay dismisses on click outside or nav item click

### Claude's Discretion
- Navigation items (derive from ROADMAP sections: Dashboard, Users, Services, Config, Monitoring, Servers, Settings)
- Header content (app title, status indicators, user avatar placeholder)
- Footer presence and content
- Sidebar animation/transition style
- Active nav item highlight style

</decisions>
