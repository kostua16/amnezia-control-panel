### Task 2: Create Login API Route
**File:** `src/app/api/auth/login/route.ts` (NEW)

POST handler:
1. Validate body with zod ({ username: string, password: string })
2. Find admin by username in Prisma
3. Compare password with bcryptjs
4. Sign JWT with jose (HS256, 24h expiry, secret from env)
5. Return { token, user: { id, username } }
6. Wire into auth-store.login() — update auth-store to call fetch('/api/auth/login')

### Task 3: Wire Login Page to API
