**Gathered:** 2026-04-28
**Status:** Ready for planning

<domain>
## Phase Boundary

Create React context for authentication state management. Provides login status, user info, login/logout methods. Shared across all components via provider. Phase 2.2-2.5 will wire real API calls.

</domain>

<decisions>
## Implementation Decisions

### Auth Context API
- **D-01:** AuthProvider wraps the app in root layout.tsx
- **D-02:** State: user (nullable), isAuthenticated (boolean), isLoading (boolean)
- **D-03:** Methods: login(username, password), logout(), checkAuth()
- **D-04:** Use zustand for state (already installed) — simpler than React context for this use case, no provider nesting needed
- **D-05:** Store in src/lib/auth-store.ts following zustand pattern

### Claude's Discretion
- Whether to use zustand or plain React context (zustand preferred — already in deps)
- Token storage strategy (deferred to Phase 2.3)
- Auth check on mount implementation details

</decisions>
