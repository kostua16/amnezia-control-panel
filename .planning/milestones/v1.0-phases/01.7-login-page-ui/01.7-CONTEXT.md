# Phase 1.7: Login Page UI - Context

**Gathered:** 2026-04-28
**Status:** Ready for planning

<domain>
## Phase Boundary

Design and implement responsive login page with username/password form. Dark theme, centered card layout, form validation, loading/error states. Phase 2.x will add real auth logic — this phase is UI only.

</domain>

<decisions>
## Implementation Decisions

### Layout & Style
- **D-01:** Centered card on dark background (bg-background). Card uses bg-card token.
- **D-02:** Logo/title "Amnezia Control Panel" at top of card, subtitle "Sign in to your account"
- **D-03:** Responsive: full-width on mobile with padding, max-w-md centered on desktop

### Form Behavior
- **D-04:** Username + password fields, both required. Min 1 char for username, min 1 for password (real validation in Phase 2.2)
- **D-05:** Submit button: full-width, bg-accent, disabled while loading
- **D-06:** Loading state: spinner on button, button text "Signing in..."
- **D-07:** Error state: red text below card title, shake animation optional

### Claude's Discretion
- Exact card padding, border radius, shadow
- Whether to show "remember me" checkbox (skip for now — single admin)
- Placeholder text for inputs
- Whether form submits via fetch or just has onClick handler (UI-only, wire in Phase 2.2)

</decisions>
