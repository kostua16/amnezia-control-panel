# Phase 2.2: Login API Endpoint - Context

**Gathered:** 2026-04-28
**Status:** Ready for planning

<domain>
## Phase Boundary

Build backend API for admin username/password authentication. POST /api/auth/login validates credentials against database, returns JWT token. Wire auth-store.login() to real API call.

</domain>

<decisions>
## Implementation Decisions

### API Design
- **D-01:** POST /api/auth/login, body: { username, password }, returns: { token, user } or { error }
- **D-02:** Validate credentials against admin user in SQLite via Prisma
- **D-03:** Return JWT token signed with jose (HS256), payload: { userId, username, exp }
- **D-04:** Password comparison with bcryptjs (already installed)
- **D-05:** Seed admin user on first run if none exists (username: admin, password: admin)

### Claude's Discretion
- JWT expiry duration (suggest 24h)
- Error response format (4xx with message)
- Rate limiting (skip for now — single admin)
- Admin user seeding strategy (check on login or on app start)

</decisions>
