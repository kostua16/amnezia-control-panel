## Manual Verification Steps

### 1. Seed admin user works
- Start dev server: `npm run dev`
- First request to `/api/auth/login` auto-seeds the admin user
- Check console for `[seed] Default admin user created (admin/admin)`

### 2. Successful login
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin"}'
```
Expected: 200 with `{ "token": "<jwt>", "user": { "id": "<cuid>", "username": "admin" } }`

### 3. Wrong password returns 401
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"wrong"}'
```
Expected: 401 with `{ "error": "Invalid credentials" }`

### 4. Unknown user returns 401
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"nobody","password":"test"}'
```
Expected: 401 with `{ "error": "Invalid credentials" }`

### 5. Validation errors return 422
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"","password":""}'
```
Expected: 422 with validation error details

### 6. JWT token is valid
Decode the returned token at jwt.io — verify:
- Header: `{ "alg": "HS256", "typ": "JWT" }`
- Payload contains: `userId`, `username`, `iat`, `exp`
- Expires in 24h from issue time
