```markdown
# Wake PR Orchestrator From Dispatched Workers

## Evidence

PR #216 reached a stale `pr-flow/ready=pending` state after Code Review completed.
The PR Orchestrator had dispatched `code-review.yml`, but no later orchestrator
run observed the completed worker and advanced the flow.

## Plan

- Keep dispatch-based PR orchestration.
- Add explicit orchestrated worker wake-ups back to `pr-flow.yml`.
- Grant `actions: write` to workers that need to dispatch the orchestrator.
- Keep `workflow_run` as a backup path rather than the only progression path.
- Add workflow invariant tests for the worker wake-up contract.
- Update workflow documentation with the dispatch-chain rule.
- Verify tests, lint, formatting, TypeScript, and workflow syntax.
```
