```markdown
# Revise Manual-Only PR Flow To Still Run Reviews

## Evidence

Recent PR-flow review showed manual-only PRs complete with code/security review
diagnostics set to N/A. That hides the advisory review signal humans need before
making the final merge decision.

## Plan

- Keep draft, closed/merged, and failed/pending/unavailable CI as early stops.
- Let manual-only PRs run Code Review and Security Review after CI passes.
- Stop manual-only PRs at `flow/manual-only` after required advisory review
  labels are present, without dispatching PR Finalizer or auto-merge.
- Keep PR Improve skipped for manual-only PRs.
- Update PR-flow visibility so manual-only reviewed PRs show review pass
  statuses and finalizer N/A.
- Extend the watchdog to wake open non-draft PRs missing current
  `pr-flow/ready`.
- Add focused orchestrator/watchdog tests and run workflow checks.
```
