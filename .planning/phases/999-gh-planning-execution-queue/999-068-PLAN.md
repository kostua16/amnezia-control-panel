# GHCR Docker Image Publishing Workflow

## Goal

Add a GitHub Actions flow that validates the project Docker image on pull requests and publishes `ghcr.io/kostua16/amnezia-control-panel` from `main` and `v*.*.*` release tags.

## Tasks

- Add `.github/workflows/docker-image.yml` with SHA-pinned Docker/GitHub actions, scoped permissions, Buildx, GHCR login, metadata tags/labels, amd64 builds, SBOM, provenance, and artifact attestation.
- Keep PR builds validation-only, while publishing from `main`, `v*.*.*` tags, and matching `workflow_dispatch` refs.
- Keep PR Docker cache usage read-only, make trusted publish cache export non-blocking and time-limited, and add a BuildKit npm cache mount for dependency installs.
- Update README Docker deployment docs with GHCR image pull/run examples.
- Add the Docker image build check to branch protection recommendations.
- Verify actionlint, workflow governance, formatting/lint/tests, and a local Docker build where the environment supports it.
