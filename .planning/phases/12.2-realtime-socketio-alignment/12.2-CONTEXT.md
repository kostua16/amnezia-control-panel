# Phase 12.2: Real-time stack (Socket.IO) - Context

**Gathered:** 2026-05-01
**Status:** Ready for planning

<domain>
## Phase Boundary

Socket.IO server attaches to the HTTP server; `broadcastEvent` delivers events to clients; `use-chain-status` uses Socket.IO client (not native WebSocket) matching the `/api/ws` path; dashboard/alert hooks use the same protocol.

Gap: PROJ-RT-01 from v1.0 audit. Three sub-issues:
1. No `instrumentation.ts` — `initWebSocket()` is never called, so `broadcastEvent` no-ops
2. `use-chain-status.ts` uses native `WebSocket` instead of Socket.IO client — protocol mismatch
3. `startBroadcaster()` in `real-time-broadcaster.ts` is never called

</domain>
