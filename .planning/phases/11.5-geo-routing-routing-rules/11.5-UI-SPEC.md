## Interaction Patterns

### Rule table (Geo tab)
- Each row: priority rank, country flag emoji + country code, action badge (Allow/Block/Route), chain name (if Route), active toggle, edit/delete actions
- Priority reorder: ChevronUp/ChevronDown buttons (same pattern as existing `RoutingRulesList`)
- Active toggle: checkbox inline (same as existing pattern)
- Inactive rows: `opacity-50` (same as existing pattern)
- Delete: inline confirmation bar at bottom of table (same pattern as existing `deleteConfirmId`)

### Rule editor drawer (Geo tab)
Fields:
- **Name**: text input, required
- **Match type**: radio group -- Country / Region / Special (domestic/foreign)
- **Country code**: searchable dropdown or text input with validation (ISO 3166-1 alpha-2)
- **Region**: dropdown (e.g., Europe, Asia-Pacific) -- shown only when match type is Region
- **Action**: radio group -- Allow / Block / Route (same as existing pattern)
- **Chain** (only if Route): dropdown of available chains
- **Priority**: number input (same as existing pattern)
- **Active**: checkbox (same as existing pattern)
- Footer: Cancel (outline) + Save Rule (default) buttons

### Template gallery (Templates tab)
- Grid of template cards, each showing: template name, description, rule count
- Each card has a "Preview" button (opens drawer with rule preview) and "Apply" button (applies template rules)
- Empty state if no templates available: "No templates available yet. Templates will be added in a future update."

### Import flow
- Triggered by "Import" button in toolbar (Geo tab or IP & Domain tab)
- Opens `Dialog` modal with:
  - File upload area (drag-and-drop or file picker, `.dat`, `.json` format)
  - Source selector: v2fly/geoip or rulite
  - After parsing: summary -- "{N} rules found. {M} conflict with existing rules."
  - If collisions: show collision list with existing vs incoming values
  - Confirmation: "Import {N} rules" (primary) or "Cancel"
  - Post-import: toast/banner -- "Imported {N} rules successfully."

### Empty state with starter rules (CONTEXT.md D-15)
- Shows on first visit when no rules exist
- Illustration area (icon or placeholder) + heading + body copy
- Primary CTA: "Load Starter Rules" -- non-destructive, adds pre-configured rules
- Secondary link: "Create Custom Rule" -- opens drawer

## Accessibility Notes

- Tab navigation: use `role="tablist"`, `role="tab"`, `role="tabpanel"`, `aria-selected`
- Drawer: follows existing `PanelDetailsDrawer` pattern -- focus trap not implemented (matches existing behavior); backdrop click closes; Escape closes
- Tables: existing `<table>` pattern with proper `<thead>`/`<tbody>`, no `role` overrides needed
- Form labels: all inputs have associated `<label>` with `htmlFor` (matching existing `CreateRoutingRuleForm` pattern)
- Focus visible: `focus-visible:ring-2 focus-visible:ring-ring` (global, already defined in `globals.css`)
- Icon-only buttons (edit, delete, ChevronUp/ChevronDown priority reorder): must include `aria-label` (e.g., `aria-label="Edit rule"`, `aria-label="Delete rule"`, `aria-label="Move rule up"`)
