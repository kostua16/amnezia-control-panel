## Decisions Made
- **Tab toggle over Tabs component**: No shadcn/ui Tabs component exists in the project. Used a custom button-based segment control with clsx conditional styling instead of adding a new dependency.
- **PushWizard as default tab**: Aligns with the audit requirement (CPUSH-01 through CPUSH-06) to make the signed remote push the primary admin flow.
- **ChainFlowEditor as secondary reference tab**: Preserves the audit requirement VISED-03 (panel boundaries visible on push screen) without displacing PushWizard.
- **buildServerPanelMap via Tailscale matching**: No foreign key exists between Server and RemotePanel in the Prisma schema. The utility matches by extracting panelUrl hostname and comparing against server tailnetIP, tailnetHostname, and hostname.
