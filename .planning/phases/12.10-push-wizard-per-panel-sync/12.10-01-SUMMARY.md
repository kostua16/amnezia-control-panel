# Phase 12.10 Plan 01: Fix Xray Rule Panel Scoping Summary

Fixed `generatePerPanelConfig` to scope Xray routing rules to the matched node only, matching the wireguardPeers pattern. Previously, all chain routing rules were sent to every panel regardless of ownership.

## What Changed

**`src/lib/panel-sync-client.ts`**: Removed the `nodeLabels` Set variable and changed the Xray routing rules filter from `nodeLabels.has(rule.nodeId)` (matches ANY chain node) to `rule.nodeId === matchedNode.label` (matches only the panel's node). This aligns with the wireguardPeers filter on line 52-53 which already uses the correct pattern.

**`src/lib/__tests__/panel-sync-client.test.ts`**: Updated the routing rules test to expect 1 rule (not 3) for panel 1, verifying the single rule is `geoip:RU` matching the "Entry Server" node.
