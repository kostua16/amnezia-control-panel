<decisions>
## Implementation Decisions

### Package Manager
- **D-01:** npm as the package manager
- Rationale: Default Node.js package manager, maximum compatibility, research already uses npm commands, no extra installation needed on deployment targets

### Project Scaffold
- **D-02:** Use `create-next-app` with all default flags: `--typescript --tailwind --eslint --app --src-dir --import-alias "@/*"`
- Rationale: Tailwind and ESLint are included now (Phase 1.5 will configure them further, but scaffolding them early avoids rework). `--src-dir` keeps source organized. `--app` for App Router (already decided in stack).

### TypeScript Configuration
- **D-03:** Use Next.js default tsconfig.json (strict: true, target ES2022, module ESNext, jsx preserve, path alias @/* → ./src/*)
- Rationale: Standard Next.js 15 configuration. No need for extra strictness at project initialization — can tighten later if needed.

### Claude's Discretion
- Exact create-next-app command and flag ordering
- Any additional tsconfig.json tweaks within Next.js defaults
- Whether to initialize git in the project (create-next-app default does this)

</decisions>
