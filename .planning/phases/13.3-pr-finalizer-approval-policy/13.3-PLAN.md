# Phase 13.3 Plan: PR finalizer and approval policy

## Goal
Replace parallel bot review verdicts with policy labels and a single finalizer that decides whether a trusted PR can be approved and set to auto-merge.

## Scope
- Convert code review and dependency review into signal producers.
- Centralize approval decisions in one workflow.
- Keep workflow/planning changes manual-only.
- Allow trusted automation PRs and safe Dependabot npm patch/minor PRs to auto-finalize.

## Deliverables
- Signal-only review workflows
- PR finalizer workflow
- Compact finalizer status comment and auto-merge enablement
