<decisions>
## Implementation Decisions

### Tailwind Theme
- **D-01:** Dark-first admin panel — dark background as default, no auto prefers-color-scheme
- **D-02:** Blue accent color on slate-900 dark background (professional server admin feel)
- **D-03:** CSS custom properties for theme tokens: bg, text, accent, borders, card surfaces
- **D-04:** Build base reusable components in this phase: Card, Button, Input (Tailwind utility classes)
- **D-05:** Phase 1.6 will add the dark mode toggle — this phase locks dark as default only

### ESLint + Prettier
- **D-06:** Install Prettier + eslint-config-prettier (disable conflicting rules)
- **D-07:** Formatting: 2 spaces, single quotes, semicolons, trailing commas
- **D-08:** Lint on save via editor config + lint:fix script in package.json

### Dev Server
- **D-09:** Default port 3000, Turbopack enabled (Next.js 16 default)
- **D-10:** Create .env.example with placeholder vars, .env.local gitignored

### Claude's Discretion
- Exact slate color values (use Tailwind's slate palette: slate-900, slate-800, etc.)
- Prettier plugin configuration details
- Whether to add lint-staged + husky for pre-commit hooks (can defer to later)

</decisions>
