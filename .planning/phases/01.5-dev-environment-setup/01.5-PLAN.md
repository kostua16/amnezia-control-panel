## Task 1: Replace globals.css with dark-first admin theme

**File:** `src/app/globals.css` (full replacement)

- Remove `@media (prefers-color-scheme: dark)` block
- Set `:root` variables directly to dark palette (no media query)
- Add full semantic token set in `:root`
- Register ALL tokens in `@theme inline {}` as `--color-*` mappings
- Use slate palette: slate-900 bg, slate-800 cards, blue-500 accents

**Token values:**
```
--background: #0f172a       (slate-900)
--foreground: #f8fafc       (slate-50)
--card: #1e293b             (slate-800)
--card-foreground: #f8fafc  (slate-50)
--muted: #334155            (slate-700)
--muted-foreground: #94a3b8 (slate-400)
--border: #334155           (slate-700)
--accent: #3b82f6           (blue-500)
--accent-foreground: #ffffff
--ring: #3b82f6             (blue-500)
--destructive: #ef4444      (red-500)
```

**Acceptance:** `@import "tailwindcss"` present, `@theme inline {}` has all `--color-*`, no `prefers-color-scheme`, `:root` set to dark values.
