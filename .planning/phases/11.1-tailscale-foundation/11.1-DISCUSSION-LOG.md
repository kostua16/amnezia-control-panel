## Tailscale Interaction

### CLI/API choice
| Option | Description | Selected |
|--------|-------------|----------|
| CLI (tailscale command) | `tailscale status` via execFile — same pattern as vpn-services.ts, no new deps | ✓ |
| Local API (localhost:10000) | HTTP GET to Tailscale local API — structured JSON, but needs daemon config | |
| JS/TS wrapper library | @aspect-build/tailscale or custom wrapper — isolation but new dependency | |

### Node status updates
| Option | Description | Selected |
|--------|-------------|----------|
| Real-time (every call) | `tailscale status` on each API call — fresh data | ✓ |
| Cached (TTL) | Periodic refresh with TTL — less CPU, stale risk | |
| Tailscale subscribe | Push notifications via `tailscale subscribe` — ideal but complex | |

### Code organization
| Option | Description | Selected |
|--------|-------------|----------|
| Thin utility (tailscale.ts) | Single file with functions: getStatus(), getNodes(), getNodeIP(), isReachable() | ✓ |
| Class-based Manager | TailscaleManager class with state — structured but overhead | |
| Extend server-connection.ts | Add Tailscale methods to existing file — one file, mixed concerns | |

### CLI binary path
| Option | Description | Selected |
|--------|-------------|----------|
| tailscale (in PATH) | Assume installed via apt/binary | |
| Configurable path | Env var or config file for custom location | |
| PATH + fallback | Try PATH first, fallback to /usr/bin/tailscale | ✓ |

| Option | Description | Selected |
