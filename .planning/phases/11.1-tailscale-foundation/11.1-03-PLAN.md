  <action>
    Create `src/app/api/servers/[id]/tailnet/route.ts` with a GET handler that resolves the Tailscale transport address for a specific server. This implements TSCL-04.

    Handler logic:
    1. Parse `{ id }` from `await context.params` (RouteContext pattern from test/route.ts)
    2. Validate `serverId = Number(id)` is not NaN, return 422 if invalid
    3. Look up server in DB: `prisma.server.findUnique({ where: { id: serverId } })`
    4. If not found: return 404 `{ success: false, error: "Server not found" }`

    **Transport address resolution strategy (D-07, TSCL-04):**
    ```
    a. If server.tailnetIP is set in DB -> use it as primary IP
    b. If server.tailnetHostname is set and tailnetIP is empty -> call getNodeIP(server.tailnetHostname)
    c. If neither is set -> call getNodeIP(server.hostname) as last resort
    d. If all lookups fail -> return { success: false, error: "Cannot resolve Tailscale IP for this server" } with 404
    ```

    5. After resolving the IP, call `isReachable(hostname)` to check online status
       - Use `server.tailnetHostname ?? server.hostname` as the hostname for reachability check
       - Per D-08: reachability is derived from tailscale status, NOT from DB

    6. Return:
    ```json
    {
      "success": true,
      "data": {
        "transportAddress": {
          "tailscaleIP": "100.x.y.z",
          "hostname": "server1.tail1234.ts.net",
          "port": 443
        },
        "online": true,
        "source": "db" | "cli-resolve" | "fallback"
      }
    }
    ```
    Where `source` indicates how the IP was obtained:
    - `"db"`: from server.tailnetIP in database
    - `"cli-resolve"`: resolved via `getNodeIP(server.tailnetHostname)`
    - `"fallback"`: resolved via `getNodeIP(server.hostname)`

    7. After successful resolution, if the IP was NOT from the DB (source !== "db"), update the server record:
    ```typescript
    await prisma.server.update({
      where: { id: serverId },
      data: {
        tailnetIP: resolvedIP,
        tailnetHostname: hostnameUsed,
      },
    });
    ```
    This caches the resolved Tailscale IP for future calls (Phase 11.2 will use this).

    Import: `import { getNodeIP, isReachable } from '@/lib/tailscale'`
    Import: `import { prisma } from '@/lib/prisma'`

    Follow the existing RouteContext pattern: `type RouteContext = { params: Promise<{ id: string }> }`
  </action>
