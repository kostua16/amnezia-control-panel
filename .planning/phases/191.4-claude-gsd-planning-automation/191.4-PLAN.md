# Phase 191.4 Plan: Claude+GSD planning automation

## Goal
Analyze qualifying PRs in a trusted planning context, generate structured follow-up suggestions, and open or refresh a draft planning PR with roadmap and phase intake updates.

## Scope
- Analyze PR diffs without executing untrusted PR head code.
- Classify follow-ups into quick tasks and 191.x phase suggestions.
- Create or update draft planning PRs on trusted planning branches.
- Keep planning PRs manual-only and human-reviewed.

## Deliverables
- PR improvement workflow
- Planning PR upsert helper
- Roadmap intake markers and per-phase suggestion sections
