# Phase 11.6: Visual Chain Editor - Context

**Gathered:** 2026-05-01
**Status:** Ready for planning

<domain>
## Phase Boundary

Replace the existing SVG-based chain builder with a React Flow powered visual chain editor that supports drag-and-drop node placement, panel boundary visualization showing which panel owns which nodes, and inline routing rule editing within the chain editor — all without navigating to a separate page.

</domain>

<decisions>
## Implementation Decisions

### Node Graph Library
- Use React Flow (@xyflow/react) as the DnD/graph library — mature, built-in DnD, minimap, fit-view, edge types
- Auto-fit view after topology change with smooth transitions
- Connection creation via drag from handle port on node edge to target node handle
- Include both minimap and zoom controls for complex topologies

### Panel Boundaries & Node Ownership
- Panel boundaries shown as dashed rectangle groups around nodes belonging to same panel, panel name label top-left
- Panel ownership derived from server→panel mapping: each server belongs to one panel, nodes with that server are in that panel's boundary
- Panels as React Flow Group nodes, chain nodes as children inside groups
- Cross-panel connections styled as thicker dashed line with panel-label tooltip on hover

### Inline Routing Rule Editing
- Trigger: click on a node opens sidebar/drawer panel with routing rules for that node's panel
- Full CRUD for geo rules + IP/host rules, priority reorder via drag, enable/disable toggle
- Rules reference chainId; editor filters rules by the chain this topology belongs to, display per-node action mapping
- Auto-save on change with debounced API call, explicit "Apply to Panels" button for push

### Claude's Discretion
Specific React Flow styling, drawer width, debounce delay, handle positioning on node edges.

</decisions>

## Existing Code Insights

### Reusable Assets
- `ChainBuilder` component (src/components/chains/chain-builder.tsx) — current SVG-based builder with topology selector, template selector, node add/remove, drag reposition, save chain. Will be REPLACED by React Flow version
- `ChainNodeCard` (src/components/chains/chain-node.tsx) — node card with role badge, protocol badge, drag handle, expand/collapse config, remove button. Can be reused as custom React Flow node
- `ChainTemplatesList` (src/components/chains/chain-templates-list.tsx) — template selection UI
- `ChainVisualization` (src/components/chains/chain-visualization.tsx) — live status visualization with traffic animation (separate from builder, keep as-is)
- `ChainLayout` (src/lib/chain-layout.ts) — calculateNodePositions, calculateConnections, NODE_WIDTH/HEIGHT constants. React Flow handles layout internally but these may inform initial positions
- Chain types (src/types/chain.ts) — ChainTopology, ChainNode, ChainTemplate, ChainConfig, ApplyChainRequest
- Remote panel types (src/types/remote-panel.ts) — RemotePanel, PanelConnectionRecord
- Geo routing types (src/types/geo-routing.ts) — GeoRoutingRule, GeoRuleCreate/Update, GeoMatchType
- Routing rule components (src/components/routing/) — geo-rules-list, geo-rule-drawer, template-apply-drawer for CRUD patterns
- Existing shadcn/ui components: Button, Card, Drawer, Badge, etc.

### Established Patterns
- 'use client' directive for interactive components
- fetch() for API calls (no SWR/React Query)
- clsx for conditional class composition
- lucide-react for icons
- shadcn/ui component library throughout
- Tailwind CSS for styling
- Custom node card components with role-based color coding
- API routes under src/app/api/

### Integration Points
- Chain builder is used in push wizard page (src/app/(dashboard)/panels/push/page.tsx)
- Chain apply API at /api/chains/apply
- Chain templates API at /api/chains/templates
- Routing rules APIs at /api/routing/geo and related routes
- Remote panels provide server-to-panel mapping needed for panel boundaries

</code_context>
