# Phase 4.2: User List Component - Context

**Gathered:** 2026-04-29
**Status:** Ready for planning

<domain>
## Phase Boundary

Create admin view showing all users with status and services. Table with columns: Name, Status, Services (AWG/3x-ui badges), Quota, Actions (block/unblock, edit, delete). Server-side search + sort. Empty state with "Create User" CTA. Data loaded via SWR/fetch with loading skeleton. Must work at 50-user scale.

</domain>

<decisions>
## Implementation Decisions

### Table Layout & Data Display
- Use SWR/fetch with loading skeleton for data loading — matches existing use-service-status pattern
- Table with columns: Name, Status, Services, Quota, Actions — standard admin table pattern
- Colored dot + badge for status (green=active, red=blocked, gray=inactive) — matches service-status component pattern
- Server-side search + sort by name/status — appropriate for 50-user scale

### Actions & Empty States
- Block/Unblock + Edit + Delete icon buttons in Actions column per row
- Empty state: "No users yet" message with "Create User" button linking to Phase 4.3
- "Create User" button in page header — positioned for Phase 4.3 integration
- Services displayed as badge pair "AWG" / "3x-ui" with color coding

### Claude's Discretion
Specific icon choices (lucide-react), exact color values, loading skeleton details, responsive breakpoints for table.

</decisions>
