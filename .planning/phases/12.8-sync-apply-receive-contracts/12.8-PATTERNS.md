## Pattern Assignments

### `src/lib/config-applier.ts` (service, request-response)

**Analog:** `src/lib/panel-sync-client.ts` -- the `pushConfigToPanel` function is the closest pattern because it already correctly signs payloads, sends auth headers, and targets a sync route. config-applier needs to adopt this same pattern.

**What to fix (3 bugs):**

1. **Missing `signPayload` import and auth headers** -- config-applier does NOT import `signPayload` from `./hmac` (line 1 area is bare). panel-sync-client already does this correctly.

2. **Missing `apiKey` parameter** -- `applyAwgConfig` (line 24) and `applyThreeXuiConfig` (line 137) accept `(panelUrl, panelName, ...)` but no `apiKey`. Must add `apiKey: string` parameter to match `pushConfigToPanel(panel: { ..., apiKey: string }, payload)` pattern.

3. **Wrong response parsing level** -- config-applier checks `data.applied` (lines 68, 78, 159, 168) but route returns `{ success, data: { applied, ... } }`. Must unwrap `resp.data` first.

**Import pattern to copy** from `src/lib/panel-sync-client.ts` (line 1):
```typescript
import { signPayload } from './hmac';
```

**Auth header pattern to copy** from `src/lib/panel-sync-client.ts` (lines 82-88):
```typescript
const signature = signPayload(payload, panel.apiKey);

const headers: Record<string, string> = {
  'Content-Type': 'application/json',
  'X-API-Key': panel.apiKey,
  'X-Signature': signature,
};
```

**Response unwrapping pattern** -- the route handlers at `src/app/api/sync/apply/route.ts` (lines 275-283) and `src/app/api/sync/receive/route.ts` (lines 135-141) both return `{ success: true, data: { applied: true, configVersion: N, ... } }`. Callers must do:
```typescript
const resp = await response.json();
const data = resp.data;  // unwrap nested data
if (data?.applied) { ... }
```

**Function signature update pattern:**
```typescript
// BEFORE (config-applier.ts line 24):
export async function applyAwgConfig(
  panelUrl: string,
  panelName: string,
  wireguardPeers: PanelSyncPayload['wireguardPeers'],
): Promise<ConfigApplierResult>

// AFTER (add apiKey parameter):
export async function applyAwgConfig(
  panelUrl: string,
  panelName: string,
  apiKey: string,
  wireguardPeers: PanelSyncPayload['wireguardPeers'],
): Promise<ConfigApplierResult>
```

Same pattern for `applyThreeXuiConfig` (line 137) and `applyPanelConfig` (line 226).
