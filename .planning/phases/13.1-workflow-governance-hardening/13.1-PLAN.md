# Phase 13.1 Plan: Workflow governance hardening

## Goal
Centralize GitHub workflow trust policy so maintainer-only triggers, trusted automation branches, blocking labels, and manual-only paths are defined once and enforced consistently.

## Scope
- Keep maintainer associations in one policy file.
- Distinguish trusted automation branches from manual-only workflow and planning branches.
- Enforce manual-only handling for `.github/**` and `.planning/**` changes.
- Route issue auto-fix through explicit maintainer intent rather than broad labels.

## Deliverables
- Shared workflow policy file and helpers
- Maintainer-gated `@claude` and `/fix` flows
- Manual-only branch/path enforcement for downstream workflows
