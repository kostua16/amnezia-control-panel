## Resolution

root_cause: |
  1. `.github/actions/run-claude-params/action.yml` uses an invalid GitHub Actions expression string literal for the optional `json-schema` CLI fragment. The expression uses double quotes inside `format(...)`, which GitHub Actions rejects in `${{ ... }}` expressions.
  2. `.github/workflows/fix-pr.yml` invokes the local composite action `./.github/actions/report-failure` from a separate `report-failure` job without checking out the repository first. `fix-issue.yml` has the same latent defect. Because each job runs on a fresh runner, the local action path is unavailable unless that job performs checkout.
fix: |
  1. Replace the three `format(" --json-schema '{0}'", inputs.json-schema)` calls in `run-claude-params/action.yml` with GitHub-valid quoting, e.g. `format(' --json-schema ''{0}''', inputs.json-schema)`, or move optional arg assembly into shell to avoid nested expression quoting entirely.
  2. Add `- uses: actions/checkout@v5` before `- uses: ./.github/actions/report-failure` in `fix-pr.yml` and `fix-issue.yml`, matching the existing pattern already used in `fix-branch.yml`.
