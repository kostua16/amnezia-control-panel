## Symptoms
- **Expected behavior**: GitHub action `claude-security-review` runs successfully.
- **Actual behavior**: Fails with error: "Claude Code failed with a non-rate-limit error. Not retrying."
- **Error messages**: `Claude Code failed with a non-rate-limit error. Not retrying.`
- **Timeline**: Recent PR / Commit.
- **Reproduction**: Run workflow #26120700396.

## Evidence
- **timestamp**: 2026-05-19
  - Log analysis reveals the true failure is from the `anthropics/claude-code-action@v1`:
  - `Attempt 1 failed: Workflow validation failed. The workflow file must exist and have identical content to the version on the repository's default branch. If you're seeing this on a PR when you first add a code review workflow file to your repository, this is normal and you should ignore this error.`
  - `App token exchange failed: 401 Unauthorized - Workflow validation failed.`

## Resolution
root_cause: "The `claude-code-action` relies on an App token exchange that validates the workflow file against the default branch. If the workflow was modified in a PR, GitHub rejects the token exchange with 401 Unauthorized."
fix: "Merge the PR or ensure the workflow file exactly matches the main/default branch. This is an expected security feature of the action for PRs."
