## Notes

- **Exact pins** (`minimatch@^3.0.0.brace-expansion`, `@prisma/config.effect`) use exact versions instead of caret ranges to prevent future minor bumps from re-introducing the vulnerable transitive path.
- All other overrides use caret ranges (`^`) for compatibility with Dependabot's weekly bump workflow — these are transitive pins where the vulnerability was in a specific older version, not ongoing.
- New override entries should be documented here and flagged in PR review per the policy (see proposal pr974.3).
- `@hono/node-server` (`^1.19.13`, origin `20bf3dc3`) was removed from `overrides` earlier; verified 2026-08-15 that no `@hono/*` package appears anywhere in `package-lock.json` (the old esbuild-RCE chain is gone), so the row was retired from the table.
- `brace-expansion` (origin `698d4839`) was removed from `overrides` on 2026-11-22 after review confirmed it was a no-op: an unqualified override rewrites *every* `brace-expansion` resolution, not just 5.x copies, and the only 5.x consumer (`minimatch@11` via `typescript-eslint`) already declares `^5.0.12` and resolves its patched copy on its own while `minimatch@3` is shielded by the version-qualified pin above. Left in place it would force-inject `5.x` into any future 1.x/2.x consumer with no install-time or audit signal, so the row was retired from the table.
